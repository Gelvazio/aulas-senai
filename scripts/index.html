🚀 AULAS-SENAI — Executor de Scripts

Dashboard centralizado para executar scripts Python de geração de aulas, ementas e análises

✨ Scripts Principais (Ativos)
📊 analisador.py ATIVO

Analisa a estrutura completa de cursos e matérias, gerando o arquivo geradoraulas.json com todas as informações de estrutura.

  • ✅ Lê pasta sistema/
  • ✅ Detecta cursos vs contêineres
  • ✅ Conta aulas e calcula tempo de leitura
  • ✅ Gera JSON estruturado
python analisador.py
Saída esperada:
✅ geradoraulas.json criado com estrutura completa
📖 converter-ementa.py ATIVO

Extrai ementas de arquivos TXT, DOCX, PDF e converte para Markdown estruturado.

  • ✅ Busca arquivos: EMENTA-*, PLANO-*, CT-*
  • ✅ Suporta: TXT, DOCX, PDF
  • ✅ Ignora aulas e avaliações
  • ✅ Formata como Markdown
python converter-ementa.py
Saída esperada:
✅ EMENTA-PRINCIPAL-*.md criados em cada curso
🎨 gerador-aulas.py LEGADO

Converte arquivos Markdown de aulas em HTML responsivo com design SENAI.

  • ✅ Parsing de Markdown com código destacado
  • ✅ Template HTML profissional
  • ✅ Dark mode suportado
  • ✅ Gera index.html navegável
python gerador-aulas.py --pasta-aulas "sistema/CURSO/AULAS" --gerar-index
Saída esperada:
✅ AULA-*.html e index.html criados
📝 gerador-ementa.py LEGADO

Consolida aulas individuais em um único arquivo de ementa estruturado.

  • ✅ Lê pasta AULAS/
  • ✅ Agrupa por matéria
  • ✅ Cria EMENTA consolidada
  • ✅ Inclui referências bibliográficas
python gerador-ementa.py
Saída esperada:
✅ EMENTA-*.md consolidado
🎭 geradorementas-aulas.py LEGADO

Orquestrador que coordena geração de aulas e ementas, produzindo relatório completo.

  • ✅ Valida estrutura do curso
  • ✅ Chama geradores em sequência
  • ✅ Produz geradoraulas.json
  • ✅ Exibe estatísticas
python geradorementas-aulas.py --caminho-curso "sistema/CURSO" --modo completo
Saída esperada:
✅ Aulas + ementas + relatório completo

🔄 Fluxo Recomendado de Execução

1️⃣
analisador.py
→
2️⃣
converter-ementa.py
→
3️⃣
gerador-aulas.py
(Opcional)

📋 Fase 1: Análise

Comando:

python analisador.py

Saída: geradoraulas.json com estrutura completa de cursos, matérias e aulas.

📖 Fase 2: Extração de Ementas

Comando:

python converter-ementa.py

Saída: EMENTA-PRINCIPAL-*.md em cada pasta de curso.

🎨 Fase 3 (Opcional): Gerar HTML de Aulas

Comando:

python gerador-aulas.py --pasta-aulas "sistema/CURSO/AULAS" --gerar-index

Saída: AULA-*.html e index.html navegável.

ℹ️ Como Usar Este Dashboard

Este arquivo index.html é um guia visual interativo para todos os scripts Python disponíveis no projeto.

Como executar os scripts:

  1. Clique no botão 📋 Copiar do script que deseja executar
  2. Abra um terminal/PowerShell nesta pasta: C:\fontes\aulas-senai\scripts
  3. Cole o comando e pressione Enter
  4. Aguarde a conclusão

📂 Estrutura de Pastas Esperada

Os scripts esperam a seguinte estrutura de projeto:

sistema/ ├── CURSO-1/ │ ├── MATERIA-A/ │ │ ├── AULAS/ │ │ ├── AVALIACOES/ │ │ └── EMENTA-*.md │ └── MATERIA-B/ ├── CONTEINER/ │ ├── SUBCURSO-1/ │ └── SUBCURSO-2/ └── CURSO-2/ └── MATERIA/

🔍 Dependências Opcionais

Para suporte completo de formatos (DOCX, PDF):

pip install python-docx pypdf

📊 Arquivos Gerados

  • geradoraulas.json — Estrutura de cursos, matérias, aulas (JSON estruturado)
  • EMENTA-PRINCIPAL-*.md — Ementas extraídas e convertidas (Markdown)
  • AULA-*.html — Aulas convertidas para HTML responsivo
  • index.html — Dashboard navegável de aulas

⚙️ Configuração

Todos os scripts usam UTF-8 por padrão. Se encontrar problemas com encoding, verifique:

  • Arquivos de origem estão em UTF-8 (não ANSI)
  • Pasta sistema/ está no local esperado
  • Arquivos de ementa seguem nomenclatura padrão

📝 Notas Importantes

  • Scripts ATIVO são os recomendados para uso
  • Scripts LEGADO estão mantidos para compatibilidade
  • Estrutura é detectada automaticamente (curso vs contêiner)
  • Rodar scripts múltiplas vezes é seguro (idempotente)
