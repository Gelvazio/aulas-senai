⭐ REGRA DE OURO

O que entra no Git fica no Git. O .gitignore só impede commits futuros — ele nunca apaga o passado. Foi por isso que o repositório anterior carregou 2,9 GB permanentes e só se resolveu começando um novo. Antes de commitar qualquer pasta gerada automaticamente (temporários de sincronização, builds, caches, node_modules), confira com git status.
