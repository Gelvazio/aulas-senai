## 🏗️ 4 FASES DO PROJETO

### FASE 1️⃣: PLANEJAMENTO (30 min)

**O QUE FAZER:**
1. Defina o tema (ex: "Análise de Segurança no Laboratório")
2. Defina público-alvo (ex: "Supervisores de turno")
3. Liste 3-4 produtos a entregar

**EXEMPLO de tema:**
- 📊 "Análise de Produção do Setor de Montagem — Janeiro 2026"
  - Público: Gerentes de produção
  - Produtos: Relatório + Planilha + Apresentação

---

### FASE 2️⃣: DOCUMENTAÇÃO (2h)

**Produto 1: RELATÓRIO TÉCNICO** (3-5 páginas)

✅ Estrutura (conforme SA-07):
- Título + Data + Autor
- Introdução (contexto, por quê?)
- Desenvolvimento (achados principais)
- Análise de dados (gráficos, tabelas)
- Conclusões (o quê aprendeu?)
- Recomendações (próximos passos)
- Referências (fontes consultadas)

✅ Formatação profissional (conforme SA-06):
- Margens 2,5 cm
- Fonte Arial 12pt
- Espaçamento 1,5
- Títulos em NEGRITO

✅ Linguagem técnica (conforme SA-07):
- Objetiva (vá ao ponto)
- Sem primeira pessoa (não "eu descobri", mas "foi descoberto")
- Termos corretos (não gíria)

---

### FASE 3️⃣: ANÁLISE DE DADOS (1h)

**Produto 2: PLANILHA COM DADOS** (conforme SA-08)

✅ Coleta:
- Mínimo 20 linhas de dados (dias, semanas, produtos)
- Reais ou simulados (mas realistas)

✅ Organização:
- Cabeçalhos claros
- Sem células vazias
- Dados bem estruturados

✅ Cálculos:
- SOMA (totais)
- MÉDIA (tendência)
- SE (categorização)
- Máximo/Mínimo

✅ Visualização:
- 1-2 gráficos (coluna, linha ou pizza)
- Título claro
- Legenda de cores

**EXEMPLO:**
```
Produção de Janeiro — Setor Montagem
┌─────────────────────────────────────┐
│ DIA │ PRODUZIDO │ META │ % ATINGIDA  │
│  1  │   145     │ 150  │  96,67%    │
│  2  │   158     │ 150  │ 105,33%    │
│ ... │   ...     │ ... │   ...%     │
│ SUM │  4.523    │4.500│ 100,51%    │
└─────────────────────────────────────┘
```

---

### FASE 4️⃣: APRESENTAÇÃO (30 min preparação + 10 min apresentação)

**Produto 3: SLIDE DECK** (conforme SA-09)

✅ Estrutura (8+ slides):
1. Capa (tema, seu nome, data)
2. Agenda (tópicos)
3. Contexto (por quê esse projeto?)
4. Metodologia (como você fez?)
5. Principais achados (gráficos, números)
6. Análise (o quê significa?)
7. Conclusões (resumo)
8. Próximos passos (recomendações)

✅ Design visual:
- Fundo uniforme
- Máximo 5-6 linhas por slide
- Imagens legíveis
- Gráficos da planilha

✅ Oralidade:
- Contato visual com público
- Voz clara e pausada
- Não decorar (usar notas)
- Praticar pelo menos 2x

## 🔟 COMPETÊNCIAS AVALIADAS

| Competência | Evidência no Projeto |
|---|---|
| **C1: Comunicação** | Relatório bem estruturado, apresentação clara |
| **C2: Segurança** | Dados tratados com sigilo (se sensíveis) |
| **C3: Uso de ferramentas** | Word + Excel + PowerPoint funcionando bem |
| **C4: Análise de dados** | Gráficos revelam insights, conclusões bem baseadas |
| **C5: Pensamento crítico** | Recomendações sensatas, conectadas aos dados |

## 📋 CHECKLIST FINAL

### Relatório:
- ☐ Título, data, autor identificáveis?
- ☐ Estrutura completa (introdução-desenvolvimento-conclusão)?
- ☐ 3-5 páginas (nem muito curto, nem muito longo)?
- ☐ Sem erros ortográficos?
- ☐ Formatação profissional (margens, fonte, espaçamento)?
- ☐ Gráficos/tabelas inseridas corretamente?

### Planilha:
- ☐ Dados bem organizados (cabeçalhos claros)?
- ☐ Fórmulas corretas (soma, média, se)?
- ☐ Gráficos legíveis (título, eixos, legendas)?
- ☐ Pronto para impresso (sem quebras estranhas)?

### Apresentação:
- ☐ 8+ slides?
- ☐ Capa, agenda, conteúdo, conclusão?
- ☐ Cores e fontes consistentes?
- ☐ Imagens e gráficos legíveis?
- ☐ Prático: consigo apresentar em 10 min?
- ☐ Faço contato visual e falo claro?

### Integração:
- ☐ Todos os 3 produtos conectados (relatório referencia dados da planilha, apresentação resume ambos)?
- ☐ Coerência: mesma história nos 3?
- ☐ Profissional: pronto para portfólio?

---

## ⭐ REGRA DE OURO

**"Seu projeto deve responder 3 perguntas claramente:"**

1. ❓ **O quê?** (tema, contexto)
2. ❓ **Por quê?** (importância, motivação)
3. ❓ **E daí?** (impacto, recomendações)

Se o público sai da apresentação com essas 3 respostas, você venceu.
