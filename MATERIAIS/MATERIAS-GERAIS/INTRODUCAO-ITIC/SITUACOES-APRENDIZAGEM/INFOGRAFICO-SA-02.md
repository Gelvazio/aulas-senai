## 3️⃣ HARDWARE vs SOFTWARE

### 🔴 ESSENCIAL — Entenda a diferença:

| Aspecto | HARDWARE | SOFTWARE |
|---------|----------|----------|
| **O quê?** | Partes físicas do computador | Programas e sistemas |
| **Toca?** | Sim, você pode tocar | Não, é invisível |
| **Exemplos** | Processador, RAM, teclado | Windows, Word, Chrome |
| **Função** | Executar as operações | Controlar o computador |
| **Quebra?** | Sim, componentes falham | Sim, travando ou lentidão |

### 💡 Analogia:

**Computador = Corpo Humano**
- HARDWARE = Órgãos, ossos, músculos
- SOFTWARE = Cérebro, instruções, comandos

## 4️⃣ COMPONENTES PRINCIPAIS DE HARDWARE

### 🔴 ESSENCIAL — 5 Componentes que você PRECISA conhecer:

#### 1. **PROCESSADOR (CPU)**
- **Função:** "Cérebro do computador" — executa todas as operações
- **Características:** Velocidade em GHz (Gigahertz)
- **Exemplo:** Intel i5, AMD Ryzen 5
- **No trabalho:** Quanto melhor, mais rápido processa dados

#### 2. **MEMÓRIA RAM**
- **Função:** Armazena dados TEMPORARIAMENTE enquanto programa roda
- **Características:** Medida em GB (Gigabytes) — típico: 4GB, 8GB, 16GB
- **CUIDADO:** Desliga quando apaga o computador
- **No trabalho:** Mais RAM = mais programas rodando ao mesmo tempo

#### 3. **DISCO RÍGIDO/SSD**
- **Função:** Armazena dados PERMANENTEMENTE (arquivos, programas, SO)
- **Características:** Capacidade em GB/TB; SSD é mais rápido que HDD
- **No trabalho:** Guarda todos seus arquivos, mesmo desligado

#### 4. **PLACA-MÃE**
- **Função:** Conecta todos os componentes, permitindo comunicação
- **Características:** Tem conectores para tudo
- **No trabalho:** Se falhar, computador não liga

#### 5. **FONTE DE ALIMENTAÇÃO**
- **Função:** Distribui energia elétrica para todos os componentes
- **Características:** Medida em Watts
- **CUIDADO:** Nunca toque se estiver aberto
- **No trabalho:** Se falhar, tudo apaga

### 🟡 IMPORTANTE — Outros componentes:

- **COOLER:** Ventilador que resfria
- **VIDRO/GABINETE:** Protege os componentes

## 5️⃣ PERIFÉRICOS (ENTRADA e SAÍDA)

### 🔴 ESSENCIAL — Periféricos de ENTRADA (você controla):

- **TECLADO:** Digita informações
- **MOUSE:** Aponta e clica
- **TOUCHPAD:** Alternativa ao mouse
- **WEBCAM:** Captura imagem (se tiver)
- **MICROFONE:** Captura som

### 🟡 IMPORTANTE — Periféricos de SAÍDA (computador mostra):

- **MONITOR:** Mostra informações (tela)
- **CAIXAS DE SOM:** Reproduz áudio
- **IMPRESSORA:** Imprime documentos (se conectada)

---

## 6️⃣ SISTEMA OPERACIONAL (SO)

### 🔴 ESSENCIAL — O quê é?

**Sistema Operacional = Intermediário entre você e o hardware**

```
VOCÊ ↔️ SISTEMA OPERACIONAL ↔️ HARDWARE
(Clica)   (Windows/Linux)     (Processa)
```

### 🟡 IMPORTANTE — Funções principais do SO:

1. **Gerenciar recursos** (CPU, RAM, disco)
2. **Permitir executar programas** (Word, Chrome, etc)
3. **Controlar periféricos** (teclado, mouse, impressora)
4. **Organizar arquivos** (pastas, documentos)
5. **Fornecer interface** (ícones, menus que você clica)

### 🟡 IMPORTANTE — Exemplos de SO:

| SO | Onde encontra? | Para quê? |
|---|---|---|
| **Windows 10/11** | Computadores empresariais | Mais comum |
| **macOS** | Computadores Mac/Apple | Edição, design |
| **Linux** | Servidores, ambientes técnicos | Gratuito, potente |

## 7️⃣ OBSERVE AGORA: MONITOR SEU COMPUTADOR

### ✅ Atividade Prática:

**Abra o Monitor de Recursos/Activity Monitor:**

1. **Windows:** Ctrl + Shift + Esc (Gerenciador de Tarefas)
2. **Mac:** Cmd + Space, digite "Activity Monitor"

**Observe:**
- Qual % de CPU está sendo usado?
- Quanto de RAM está em uso?
- Quais programas estão rodando?

## 8️⃣ RELACIONE COMPONENTES ÀS TAREFAS

### 💡 Exemplo no trabalho industrial:

**Tarefa:** "Abrir relatório em Excel + fotografar equipamento + enviar email"

**Componentes envolvidos:**

| Tarefa | Componente usado | Por quê? |
|--------|---|---|
| Abrir Excel | CPU + RAM | Processa cálculos |
| Fotografar | Câmera/periférico | Captura imagem |
| Enviar email | Rede/HD | Armazena, transmite |
| Tudo junto | CPU + RAM | Ambos rodam simultaneamente |

## 🟣 CUIDADOS COM HARDWARE

### 🔴 NUNCA faça isso:

❌ Derramar bebida perto do computador  
❌ Transportar computador ligado (batidas danificam HD)  
❌ Colocar computador no chão (poeira)  
❌ Ignorar alarmes de superaquecimento  
❌ Puxar cabos abruptamente  

### ✅ SEMPRE faça isso:

✅ Manter computador em local seco e limpo  
✅ Desligar antes de movimentar  
✅ Fazer backup de arquivos importantes  
✅ Verificar se coolers estão funcionando  
✅ Informar ao gestor se notar problemas
