## 🎯 Estrutura de Cada Formulário

### Seção 1: Identificação (Obrigatória)
- Nome completo
- Número de matrícula/RA
- Data e hora (automática)

### Seção 2: Questões de Avaliação
- Múltipla escolha (com resposta correta)
- Resposta curta (validação manual)
- Seleção de itens
- Cada questão tem valor de ponto

### Seção 3: Resultado Final (Automático)
- ✅ **Nota obtida** (pontos corretos)
- ✅ **Percentual de acerto** (%)
- ✅ **Feedback personalizado** baseado no desempenho
- ✅ **Recomendações de estudo** se score < 70%

## 🔐 Sistema de Feedback Automático

### Após submeter o formulário, o aluno vê:

#### ✅ Nota Numérica (0-10)
```
Sua nota: 8,5/10
Percentual: 85%
```

#### 📊 Barra de Progresso Visual
```
████████░░ 85%
```

#### 💬 Feedback Personalizado

**Se score ≥ 90%:**
```
🌟 Excelente! Você dominou completamente o conteúdo!
Continue assim — você está indo muito bem!
```

**Se 70% ≤ score < 90%:**
```
✅ Muito bom! Você compreendeu bem o conteúdo.
Revise os tópicos com menor percentual de acerto.
```

**Se 50% ≤ score < 70%:**
```
⚠️ Bom começo! Você acertou mais da metade.
Estude novamente os tópicos indicados abaixo.
Não hesite em pedir ajuda ao professor.
```

**Se score < 50%:**
```
💡 Você pode melhorar! 
Revise o conteúdo com o professor.
Tem direito a refazer a avaliação após estudo orientado.
```

#### 📚 Recomendações por Tópico
Mostra em quais tópicos o aluno errou:
```
❌ Acertou: 8/10
   • Elementos da comunicação ✅
   • Ruído e feedback ❌
   • Linguagem profissional ✅
```

#### 🔄 Próximos Passos
```
→ Próxima aula: Aula 02 — Hardware e SO
→ Data: [data planejada]
→ Link do formulário: [link]
```
