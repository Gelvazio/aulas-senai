## 📝 Estrutura Padrão para Cada Aula

### Seção 1: Objetivos (introdução)
**Exemplo para AULA-01:**
```
Ao final desta aula, o aluno será capaz de:
✓ Compreender a evolução histórica da computação (5 gerações)
✓ Diferenciar hardware de software com exemplos práticos
✓ Identificar periféricos e suas funções (entrada, saída, armazenamento)
✓ Operar com segurança um PC (mouse, teclado, menus)
✓ Organizar pastas e arquivos no sistema de arquivos Windows
✓ Reconhecer o papel do sistema operacional
✓ Resolver problemas básicos de usabilidade
```

### Seção 2-8: Conteúdo Programático (7-10 seções)
Cada seção tem:
- **Tempo:** 20-50 minutos
- **Descrição:** Resumo em 3-5 linhas
- **Tópicos:** Lista com 5-10 sub-tópicos
- **Exemplos:** Casos práticos, screenshots, diagramas
- **Atividade:** Exercício interativo ou prático

**Estrutura HTML de cada toggle:**
```html
<div class="toggle-item">
  <button class="toggle-btn">
    <span>N. Título do Tópico (tempo min)</span>
    <span class="toggle-icon">▼</span>
  </button>
  <div class="toggle-content hidden">
    <p><strong>Descrição:</strong> ...</p>
    <ul>
      <li>Subtópico 1</li>
      <li>Subtópico 2</li>
      ...
    </ul>
    <div class="bg-blue-50 p-4 rounded">
      <strong>💡 Exemplo Prático:</strong> ...
    </div>
  </div>
</div>
```

### Seção 9: Quiz Expandido (8-15 questões)
- Múltipla escolha (A-E)
- 1 questão certa, 4 erradas
- Gabarito corrigido
- Feedback por resposta (correto/incorreto)

**Exemplo:**
```html
<div class="quiz-item bg-blue-50 border-l-4 border-blue-500 p-4 mb-4">
  <p class="font-bold">❓ Qual é a principal função de um SO?</p>
  <label>
    <input type="radio" name="q2" value="a">
    Gerenciar hardware e software, oferecer interface
  </label>
  <label>
    <input type="radio" name="q2" value="b">
    Apenas proteger contra vírus
  </label>
  <label>
    <input type="radio" name="q2" value="c">
    Apenas abrir programas
  </label>
  <label>
    <input type="radio" name="q2" value="d">
    Apenas gerenciar pastas
  </label>
  <label>
    <input type="radio" name="q2" value="e">
    Nenhuma das anteriores
  </label>
  <button class="check-btn" data-correct="a">✓ Verificar</button>
  <div class="feedback hidden"></div>
</div>
```

### Seção 10: Atividades Práticas
Sempre com **4 atividades** (duração total ~30-45 min):

1. **Atividade 1 (Desplugada)** — Não precisa computador (discussão, brainstorm)
2. **Atividade 2 (Prática)** — Exercício no computador
3. **Atividade 3 (Colaborativa)** — Trabalho em grupo
4. **Atividade 4 (Reflexão)** — Registro/portfólio

### Seção 11: Recursos Necessários
- Software necessário
- Arquivos de exemplo
- Links e referências
- Configurações recomendadas
- Tempo de setup

## 🎯 Detalhamento por Aula

### 1️⃣ AULA-01 — Introdução à Computação (já em andamento)

**7 Seções = 240 min:**
1. Acolhimento e diagnóstico (20 min)
2. História da Computação (50 min) — 5 gerações
3. Hardware × Software (45 min) — componentes internos + periféricos
4. Mouse: uso e domínio (30 min) — prática guiada
5. Teclado: regiões e atalhos (35 min) — Ctrl+C, Alt+Tab, etc
6. Área de Trabalho (25 min) — ícones, taskbar, system tray
7. Pastas e Arquivos (35 min) — caminhos, organização, busca

**Quiz:** 8 questões  
**Atividades:** 4 (1 desplugada, 3 práticas)  
**Recursos:** Windows 10+, Explorador, navegador

## ⚠️ Riscos e Mitigações

| Risco | Prob | Mitigação |
|-------|------|-----------|
| Conteúdo fica muito longo | Alta | Manter 3-5 linhas por seção, não exagerar |
| Quiz com gabarito errado | Média | Revisar CADA questão manualmente |
| HTML quebrado/malformado | Média | Testar NO NAVEGADOR após cada geração |
| Tempo de execução muito longo | Alta | Gerar 2-3 aulas por sessão, não 10 de uma vez |
| Inconsistência entre aulas | Alta | Usar template padrão para TODAS |
