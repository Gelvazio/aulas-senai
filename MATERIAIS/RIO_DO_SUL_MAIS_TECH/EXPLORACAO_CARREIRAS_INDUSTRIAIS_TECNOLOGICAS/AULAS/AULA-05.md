# AULA-05: Plataformas de Emprego e Networking

**Matéria:** EXPLORAÇÃO DE CARREIRAS INDUSTRIAIS E TECNOLÓGICAS | **Duração:** 4h

---

## 🎯 Objetivo

- Explorar plataformas de emprego
- Compreender importância de networking
- Desenvolver contatos profissionais

---

## 📚 Conteúdo

### 1. Plataformas de Emprego

**LinkedIn Jobs:** Rede profissional, muitas oportunidades

**Indeed:** Maior base de vagas no Brasil

**Glassdoor:** Avaliações de empresas

**Se Rh:** Recrutamento especializado

**Lokoja:** Oportunidades regionais

### 2. Networking Profissional

**Valor:** Muitos empregos são preenchidos via contatos

**Estratégia:** Construir relacionamentos autênticos

**Onde:** Eventos, conferências, grupos profissionais, alumni

### 3. Como Fazer Networking

- Apresentar-se de forma clara
- Ouvir atentamente
- Seguir nos social media
- Manter contato regularmente
- Oferecer valor (informações, contatos, apoio)

### 4. Comunicação Profissional

Email, telefone, mensagem - tudo importa
