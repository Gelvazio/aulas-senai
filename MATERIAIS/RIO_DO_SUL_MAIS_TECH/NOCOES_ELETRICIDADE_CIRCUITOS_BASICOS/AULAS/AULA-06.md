# AULA-06: Circuitos em Paralelo

**Matéria:** NOÇÕES DE ELETRICIDADE E CIRCUITOS BÁSICOS | **Duração:** 4h

---

## 🎯 Objetivo

- Compreender circuitos paralelos
- Calcular valores
- Comparar com série

---

## 📚 Conteúdo

### 1. Característica Paralelo

**Mesma tensão:** Todos componentes recebem U

**Correntes diferentes:** I_total = I1 + I2 + I3

**Resistência Total:** 1/R_t = 1/R1 + 1/R2 + 1/R3

### 2. Fórmulas

I_total = I1 + I2 + I3  
U = U1 = U2 = U3  
1/R_t = 1/R1 + 1/R2 + 1/R3  

### 3. Vantagem

Se um componente falha, outros continuam funcionando

### 4. Aplicação Prática

Casas usam circuitos paralelo (lâmpadas independentes)

---

## 🎯 Atividades

### Atividade 1: Montagem (80 min)
Montar circuito paralelo com resistores e lâmpadas.

### Atividade 2: Comparação (40 min)
Série vs Paralelo - observar diferenças.
