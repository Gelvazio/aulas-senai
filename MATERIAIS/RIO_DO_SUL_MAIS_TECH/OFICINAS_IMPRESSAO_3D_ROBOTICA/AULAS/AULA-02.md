---

## 🎯 Objetivo

- Usar Tinkercad para modelagem
- Criar sólidos básicos
- Exportar arquivos STL

---

## 📚 Conteúdo

### 1. Interface Tinkercad

- Menu superior (Shapes, Workplane)
- Editor 3D (arraste/escala)
- Propriedades (tamanho, cor)
- Visualização (zoom, rotação)

### 2. Formas Básicas

- Cubo
- Esfera
- Cilindro
- Cone
- Toro

### 3. Operações

- Mover
- Girar
- Escalar
- Agrupar
- Furos (booleano)

### 4. Exportação STL

Arquivo para impressora 3D
