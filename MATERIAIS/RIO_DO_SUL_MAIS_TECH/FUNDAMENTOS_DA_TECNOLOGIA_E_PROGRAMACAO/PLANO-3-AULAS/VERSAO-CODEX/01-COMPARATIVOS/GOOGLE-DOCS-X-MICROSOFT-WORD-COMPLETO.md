# 📄 Google Docs vs Microsoft Word

**Editores de Texto • Comparação Profissional**

---

## 1. ☁️ Visão Geral - Google Docs

**Plataforma:** Web-based + app desktop

**Custo:** Gratuito com Google Account

**Armazenamento:** Google Drive (15GB grátis)

**Ideal para:** Equipes colaborativas, documentos dinâmicos

Sem software para instalar

Acesso de qualquer dispositivo

Histórico de versões infinito

## 2. 🔄 Colaboração Real-time

**Múltiplos usuários editam simultaneamente:**

Cursor de cada pessoa em cor diferente

Histórico de versões automático

Comentários com threads resolvíveis

Sugestões de mudanças integradas

💡 Perfeito para equipes remotas - edição simultânea funciona perfeitamente

## 3. 🎨 Formatação Básica

**Recursos disponíveis:**

Estilos básicos (parágrafos, fontes)

Tabelas simples com mesclagem

Cabeçalhos e estrutura de documento

Imagens e comentários

⚠️ Não tem recursos avançados como índices automáticos ou notas de rodapé complexas

## 4. 📤 Exportação

**Formatos suportados:**

Google Docs → .docx (Word)
↓
PDF • ODP • RTF • TXT

✓ Compatibilidade DOCX: ~95% (alguns ajustes necessários)

## 5. ✨ Vantagens Principais

**Colaboração sem paralelo** - múltiplos editores tempo real

**Histórico infinito** - recupere qualquer versão

**Gratuito** - nenhuma assinatura necessária

**Nuvem nativa** - acesso de qualquer lugar

## 6. ⚡ Limitações

**Formatação limitada** vs Word profissional

**Sem índices automáticos** (livros, teses)

**Sem macros** ou automação avançada

**Offline limitado** vs desktop-first

## 7. 📝 Visão Geral - Microsoft Word

**Plataforma:** Desktop (Windows/Mac) + Web + Mobile

**Custo:** Microsoft 365 ($6,99/mês) ou licença perpétua

**Armazenamento:** OneDrive (5GB grátis, sincronizado)

**Ideal para:** Documentos corporativos complexos, impressão

Padrão de facto corporativo

Formatação profissional avançada

Offline-first, sem dependência de internet

## 8. 🏢 Formatação Avançada

**Recursos profissionais:**

Estilos profundos e customizáveis

Índices automáticos (conteúdo, referências)

Notas de rodapé e referências cruzadas

Cabeçalhos/rodapés dinâmicos por seção

Tabelas complexas com cálculos

✓ Padrão industrial para documentos acadêmicos e corporativos

## 9. ✏️ Rastreamento de Alterações

Rastreamento ativado
↓
Aceitar/rejeitar mudanças
↓
Histórico completo

Marca quem mudou o quê e quando

Aceitar ou rejeitar mudanças individuais

Comentários associados a mudanças

## 10. 🔗 Co-autoria (OneDrive)

**Colaboração em tempo real (sincronizada):**

Desktop + Web podem editar simultaneamente

Histórico de versões (OneDrive)

Permissões granulares (SharePoint)

Notificações de atividade

⚠️ Menos fluida que Google Docs (não é tempo real puro)

## 11. ⭐ Vantagens Principais

**Formatação profissional** - índices, notas, estilos

**Padrão corporativo** - esperado em empresas

**Offline-first** - não precisa internet constante

**Rastreamento robusto** - controle de mudanças profissional

## 12. ❌ Limitações

**Pago** - Microsoft 365 assinatura

**Curva de aprendizado** - mais complexo que Docs

**Colaboração menos fluida** vs Google (não é tempo real puro)

**Arquivo único** - não nuvem-nativa como Docs

## 13. ⚖️ Comparação Lado-a-Lado (6 Critérios)

💰 CUSTO

**Google Docs:** ✓ Gratuito (15GB)
**Word:** ✗ Microsoft 365 ($6,99/mês)

🌐 PLATAFORMAS

**Google Docs:** ✓ Qualquer navegador
**Word:** ✓ Windows, Mac, Web, Mobile

📊 ARMAZENAMENTO

**Google Docs:** ✓ 15GB gratuito (Drive)
**Word:** ⚠️ 5GB (OneDrive) ou local

🔄 COLABORAÇÃO

**Google Docs:** ✓ Tempo real fluido
**Word:** ⚠️ Tempo real sincronizado

📝 FORMATAÇÃO

**Google Docs:** ⚠️ Básica
**Word:** ✓ Profissional avançada

🎯 MELHOR PARA

**Google Docs:** Equipes remotas
**Word:** Documentos corporativos

## 14. 🎯 Matriz de Decisão

**Qual escolher? Responda estas perguntas:**

**1. Você trabalha em equipe remota?**
SIM → Google Docs (colaboração real-time) | NÃO → Word

**2. Precisa de formatação profissional?**
SIM → Microsoft Word (índices, notas, etc.) | NÃO → Google Docs

**3. Seu orçamento é limitado?**
SIM → Google Docs (gratuito) | NÃO → Word (Microsoft 365)
