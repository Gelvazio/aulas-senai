## CONTEÚDO PROGRAMÁTICO
## 1. CONCEITO DE TABELA DINÂMICA

### 1.1 Definição
- Resumo automático de grandes volumes de dados
- Reorganiza dados sem modificar original
- Atualiza dinamicamente ao mudar fonte

### 1.2 Vantagens
- Análise rápida de milhares de linhas
- Múltiplas perspectivas dos mesmos dados
- Não altera dados originais

### 1.3 Estrutura
- **Linhas:** Categorias (ex: Mês, Produto)
- **Colunas:** Subcategorias (ex: Região)
- **Valores:** Dados a resumir (ex: Vendas, Quantidade)
- **Filtros:** Segmentação de dados

## 2. CRIAÇÃO DE TABELA DINÂMICA

### 2.1 Passos
1. Selecionar intervalo com dados (incluir cabeçalho)
2. Menu: Inserir > Tabela Dinâmica
3. Escolher: Nova planilha ou existente
4. Arrastar campos para área apropriada

### 2.2 Exemplo Prático
- Dados: Data, Produto, Categoria, Vendedor, Valor
- Criar tabela com:
  - Linhas: Produto
  - Colunas: Mês
  - Valores: SUM(Valor)

Resultado: Matriz Produto × Mês com totais

## 3. FILTROS E SEGMENTAÇÃO

### 3.1 Filtro Automático
- Botões dropdown em cabeçalhos
- Desmarcar items não desejados
- Mostrar apenas valores específicos

### 3.2 Filtro Avançado
- Menu: Dados > Filtro Avançado
- Criar critérios customizados
- Exemplo: Vendas > R$1.000 E Região = "Sul"

### 3.3 Slicer (Segmentador)
- Visual filter para tabelas dinâmicas
- Cliques em botões para filtrar
- Menu: Tabela Dinâmica > Inserir Slicer

## 4. ORDENAÇÃO E AGRUPAMENTO

### 4.1 Ordenação
- Clicar em campo e escolher A→Z ou Z→A
- Ordenar por valores (maior para menor)
- Múltiplos níveis de ordenação

### 4.2 Agrupamento
- Agrupar por período (Data → Mês/Ano)
- Agrupar por faixa (Valor → Faixas de 1000)
- Colapsar/expandir grupos

### 4.3 Subtotais
- Mostrar subtotais por grupo
- Criar totalização em múltiplos níveis
- Exemplo: Total por Produto, Total Geral

## 5. ATUALIZAÇÃO

### 5.1 Modo Manual
- Botão direito > Atualizar
- Menu: Tabela Dinâmica > Atualizar

### 5.2 Atualização Automática
- Propriedades > Dados
- Marcar "Atualizar ao abrir arquivo"

### 5.3 Mudança de Dados
- Modificar tabela original
- Atualizar tabela dinâmica
- Segue os novos dados automaticamente
