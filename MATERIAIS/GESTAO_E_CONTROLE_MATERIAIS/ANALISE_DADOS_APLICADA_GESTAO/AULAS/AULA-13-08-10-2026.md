## CONTEÚDO PROGRAMÁTICO
## 1. FILTRO AUTOMÁTICO

### 1.1 Ativação
- Selecionar intervalo com dados
- Menu: Dados > Filtro Automático
- Aparecem botões dropdown no cabeçalho

### 1.2 Uso
- Clicar botão dropdown
- Desmarcar items não desejados
- Marcar "Tudo" para remover filtro
- Dados ocultados aparecem em azul

### 1.3 Exemplos
- Filtrar por período (Jan, Fev, Mar)
- Mostrar apenas vendas acima de X
- Filtrar por departamento (RH, TI, Vendas)

## 2. FILTRO AVANÇADO

### 2.1 Sintaxe
- Menu: Dados > Filtro Avançado
- Definir intervalo de critério
- Exemplo: Valor > 1000 E Status = "Pago"

### 2.2 Critérios Múltiplos
- E (intersecção): Ambas condições verdadeiras
- OU (união): Qualquer uma condição verdadeira
- NÃO (negação): Excluir valores

### 2.3 Exemplo Prático
Tabela de critérios:
| Região | Status |
|--------|--------|
| Sul | Entregue |
| Sul | Entregue |

Filtra: Todas vendas do Sul com Status Entregue

## 3. VALIDAÇÃO DE DADOS

### 3.1 Conceito
- Restringe entrada de dados
- Garante consistência
- Previne erros

### 3.2 Tipos de Validação
- **Lista:** Escolher de opções predefinidas
- **Número:** Apenas números em intervalo
- **Data:** Apenas datas em período
- **Texto:** Comprimento ou padrão específico

### 3.3 Criação
1. Selecionar célula/intervalo
2. Menu: Dados > Validação de Dados
3. Escolher tipo
4. Definir critérios
5. Mensagem de erro (opcional)

### 3.4 Exemplo: Lista Suspensa
- Validação > Lista
- Fonte: "Ativo", "Inativo", "Pausado"
- Resultado: Dropdown com 3 opções

## 4. PROTEÇÃO

### 4.1 Proteger Células
1. Selecionar células a proteger
2. Formato > Célula > Proteção > Marcar "Protegido"
3. Menu: Ferramentas > Proteger Planilha

### 4.2 Proteger Planilha
- Senha para editar
- Selecionar o que é permitido (inserir linhas, etc)
- Mensagem ao tentar editar

### 4.3 Proteger Workbook
- Senha para adicionar/remover planilhas
- Ocultar planilhas
- Proteger estrutura do arquivo

### 4.4 Aplicação Prática
- Proteger fórmulas, permitir entrar dados
- Usuários veem apenas células editáveis
- Previne alterações acidentais
