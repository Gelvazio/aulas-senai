## CONTEÚDO PROGRAMÁTICO
## 1. TIPOS DE GRÁFICOS

### 1.1 Gráfico de Colunas
- **Uso:** Comparar valores entre categorias
- **Exemplo:** Vendas por departamento
- **Variação:** Coluna empilhada, % empilhada

### 1.2 Gráfico de Linhas
- **Uso:** Tendências ao longo do tempo
- **Exemplo:** Vendas mês a mês
- **Variação:** Com marcadores, área preenchida

### 1.3 Gráfico de Setores (Pizza)
- **Uso:** Composição de um total
- **Exemplo:** Participação % por produto
- **Limitação:** Máximo 6-7 categorias

### 1.4 Gráfico de Barras
- **Uso:** Comparação horizontal (mais rápido ler nomes)
- **Exemplo:** Vendedor com maior vendas
- **Diferença:** Barras em vez de colunas

### 1.5 Gráfico de Dispersão (XY)
- **Uso:** Correlação entre duas variáveis
- **Exemplo:** Relação preço × demanda
- **Tipo:** Pontos, com linhas, etc

## 2. CRIAÇÃO DE GRÁFICOS

### 2.1 Passos
1. Selecionar dados (incluir cabeçalhos)
2. Menu: Inserir > Gráfico
3. Escolher tipo
4. Ajustar dados (séries, categorias)
5. Adicionar título e labels
6. Inserir no documento

### 2.2 Seleção de Dados
- Colunas contíguas: Fácil (Excel detecta automático)
- Colunas não contíguas: Usar Ctrl+Click
- Incluir cabeçalho em primeira linha

## 3. FORMATAÇÃO DE GRÁFICOS

### 3.1 Títulos e Labels
- **Título do Gráfico:** Descrição principal
- **Título do Eixo X:** O que é medido horizontalmente
- **Título do Eixo Y:** O que é medido verticalmente
- **Legenda:** Identificar séries de dados

### 3.2 Cores e Estilos
- Mudar cores das colunas/linhas
- Alterar fonte e tamanho
- Adicionar padrões/texturas
- Ajustar tamanho do gráfico

### 3.3 Eixos
- Ajustar mínimo/máximo do eixo Y
- Formato de números (moeda, %)
- Rótulos das categorias (rotação de texto)

## 4. GRÁFICOS DINÂMICOS

### 4.1 Baseados em Tabela Dinâmica
- Criar tabela dinâmica primeiro
- Inserir gráfico baseado na tabela
- Filtrar tabela afeta gráfico automaticamente

### 4.2 Aplicação
- Relatório executivo com filtro visual
- Dashboard interativo
- Análise por múltiplas dimensões

## 5. GRÁFICOS COMBINADOS

### 5.1 Conceito
- Combinar dois tipos em um gráfico
- Usar eixo secundário se escalas diferentes
- Exemplo: Colunas (quantidade) + Linha (preço)

### 5.2 Criação
1. Criar gráfico de colunas
2. Clicar em uma série
3. Menu: Formatar Série > Eixo Secundário
4. Muda para linha/barras conforme necessário

### 5.3 Exemplo Prático
- Eixo esquerdo: Quantidade (colunas)
- Eixo direito: Preço médio (linha)
- Visualiza relação inversa quantidade-preço
