Módulo 1: Fundamentos Matemáticos

Introdução à Estatística Básica

2 horas | Análise de Dados Aplicada à Gestão

📚 Objetivos da Aula

  • Compreender conceitos fundamentais de estatística
  • Calcular média, mediana e moda
  • Entender dispersão de dados
  • Aplicar análise estatística em dados operacionais

Conceitos Fundamentais

  • Dados: Informações brutas coletadas
  • Amostra: Subconjunto de dados
  • Variável: Características que podem variar
  • Frequência: Número de vezes que um valor aparece

Tipos de Dados

Quantitativos: Números (idade, salário, quantidade)

Qualitativos: Categorias (sexo, departamento, produto)

Média Aritmética

Fórmula: Soma de todos valores ÷ Quantidade

Exemplo: Vendas 100, 120, 150, 130

Média = (100+120+150+130) ÷ 4 = 125

Em Excel: =MÉDIA(intervalo)

Mediana e Moda

Mediana: Valor que divide o conjunto ao meio

Exemplo: 100, 120, 130, 150, 200 → Mediana = 130

Moda: Valor que mais frequentemente aparece

Exemplo: 100, 100, 120, 150, 200 → Moda = 100

Medidas de Dispersão

  • Amplitude: Máximo - Mínimo (ex: 200-100 = 100)
  • Variância: Média dos quadrados das diferenças
  • Desvio Padrão: Raiz da variância (quanto dados se desviam)

Em Excel: =DESVPAD(intervalo)

Tabelas de Frequência

Processo:

  1. Listar valores únicos
  2. Contar quantas vezes cada valor aparece
  3. Calcular frequência relativa (freq/total)
  4. Analisar padrões

Aplicação Prática

Cenário: Análise de vendas diárias

  • Média de vendas = R$ 5.000/dia
  • Mediana = R$ 4.800 (metade acima/abaixo)
  • Desvio Padrão = R$ 1.200 (variação típica)
  • Amplitude = R$ 2.500 (diferença min-max)

💻 Atividades Práticas (2 horas)

Atividade 1 (30 min): Cálculo de medidas centrais

Atividade 2 (25 min): Análise de dispersão

Atividade 3 (25 min): Construção de tabelas

📝 Resumo da Aula

  • Estatística descreve dados através de números
  • Média, mediana e moda resumem tendências
  • Desvio padrão mede variabilidade
  • Tabelas de frequência revelam padrões
