# PLANO DE AULAS AJUSTADO: Análise de Dados Aplicada à Gestão

**Unidade Curricular:** Análise de Dados Aplicada à Gestão  
**Módulo:** Específico da Ocupação  
**Carga Horária Total:** 32 horas  
**Distribuição:**
- Aulas teóricas e práticas: 28 horas (7 aulas × 4h)
- Avaliação Integrada: 4 horas (1 aula)

**Turma:** Salete 2026/02  
**Período:** Semestral

---

## 1. OBJETIVOS DE APRENDIZAGEM

Ao final da unidade curricular, os alunos serão capazes de:

1. **Compreender** os fundamentos de operações matemáticas aplicadas à gestão
2. **Aplicar** conceitos de estatística básica em análise de dados
3. **Utilizar** planilhas eletrônicas com recursos avançados
4. **Criar** dashboards para visualização de dados gerenciais
5. **Resolver** problemas de gestão através da análise de dados

---

## 2. ESTRUTURA DO PLANO (28 horas de aulas + 4h avaliação)

### **AULA 1: FUNDAMENTOS MATEMÁTICOS — PARTE 1 (4h)**

**Tópicos:** Conjuntos Numéricos, Proporção e Regra de Três

#### Conteúdo
- Números naturais, inteiros, racionais e reais
- Operações básicas e aplicações em contextos empresariais
- Razão e proporção em análises empresariais
- Regra de três simples e composta
- Aplicações em gestão de materiais e custos

#### Atividades Práticas
1. Exercícios de cálculos com dados empresariais reais
2. Resoluções de problemas de proporção em casos de gestão
3. Aplicação de regra de três em problemas de produção

#### Recursos
- Computador, calculadora, planilha eletrônica
- Dados de exemplo de empresas parceiras

---

### **AULA 2: FUNDAMENTOS MATEMÁTICOS — PARTE 2 (4h)**

**Tópicos:** Porcentagem, Estatística Básica e Sequência Lógica

#### Conteúdo
- Porcentagem e variações percentuais
- Aplicações em análise de custos, descontos e lucros
- Média, mediana e moda
- Variância e desvio padrão
- Tabelas de frequência e aplicações em gestão
- Progressões aritméticas e geométricas
- Lógica de causa e efeito em previsões empresariais

#### Atividades Práticas
1. Exercícios de cálculo de margem, desconto e variação
2. Análise de dados com cálculo de medidas estatísticas
3. Identificação de padrões e previsões em datasets

#### Recursos
- Excel com fórmulas
- Dados reais de operações
- Problemas contextualizados de gestão

---

### **AULA 3: EXCEL BÁSICO — INTERFACE E FÓRMULAS (4h)**

**Tópicos:** Excel Básico, Navegação, Fórmulas e Funções Essenciais

#### Conteúdo
- Interface do Excel: planilhas, abas, células, linhas e colunas
- Entrada e formatação básica de dados
- Fórmulas básicas e operadores
- Funções essenciais: SUM, AVERAGE, COUNT
- Função IF (SE) para lógica condicional
- Referências absolutas e relativas
- Cópia de fórmulas e propagação

#### Atividades Práticas
1. Criar planilha com dados de exemplo e estrutura bem organizada
2. Criar planilha de folha de pagamento com fórmulas automatizadas
3. Implementar função IF para classificações condicionais

#### Recursos
- Computador com Excel 2016+
- Dados de RH e gestão como exemplos
- Laboratório de informática

---

### **AULA 4: EXCEL INTERMEDIÁRIO — FORMATAÇÃO E VALIDAÇÃO (4h)**

**Tópicos:** Formatação Profissional, Congelamento, Validação de Dados

#### Conteúdo
- Formatação de células: números, moedas, percentuais, datas
- Formatação condicional básica para destaque de valores
- Bordas, cores, fontes e estilos
- Congelamento de painéis para navegação eficiente
- Validação de dados e listas suspensas
- Proteção de células e planilhas
- Filtro automático básico

#### Atividades Práticas
1. Formatar planilha de relatório gerencial com dados reais
2. Criar planilha com validação de dados e listas suspensas
3. Implementar proteção de planilhas para preservação de dados

#### Recursos
- Excel com dados estruturados
- Exemplos de relatórios gerenciais
- Dados de produção e vendas

---

### **AULA 5: EXCEL AVANÇADO — FUNÇÕES COMPLEXAS (4h)**

**Tópicos:** Funções de Busca, Lógica Condicional Avançada, Agregações

#### Conteúdo
- Função PROCV (VLOOKUP) para consultas verticais
- Função PROCH (HLOOKUP) para consultas horizontais
- Função ÍNDICE e CORRESPONDÊNCIA para buscas complexas
- Tratamento de erros com IFERROR
- Função SE aninhada para lógicas condicionais múltiplas
- Função CONTSE (COUNTIF) para contagens condicionais
- Função SOMASE (SUMIF) para somas condicionais
- Aplicações em análises de vendas e estoque

#### Atividades Práticas
1. Criar consultas entre tabelas de produtos e fornecedores
2. Análise de vendas com condições múltiplas (categorias, períodos)
3. Implementar agregações condicionais para relatórios gerenciais

#### Recursos
- Excel com base de dados de exemplo
- Produtos, preços, vendas, estoque
- Dados de fornecedores e custos

---

### **AULA 6: EXCEL AVANÇADO — TABELAS DINÂMICAS E GRÁFICOS (4h)**

**Tópicos:** Pivot Tables, Filtros Dinâmicos, Gráficos e Visualizações

#### Conteúdo
- Criação de tabelas dinâmicas a partir de dados brutos
- Filtros em tabelas dinâmicas
- Ordenação e agrupamento de dados
- Aplicações em análise de vendas e estoque
- Tipos de gráficos: colunas, linhas, setores, scatter
- Criação de gráficos dinâmicos vinculados a dados
- Formatação e estilização de gráficos
- Gráficos combinados e múltiplos eixos

#### Atividades Práticas
1. Criar tabela dinâmica de dados de vendas com filtros
2. Desenvolver múltiplas perspectivas de análise (por categoria, período, fornecedor)
3. Criar gráficos diversos para relatório gerencial

#### Recursos
- Excel com base de dados de transações
- Dados de vendas, estoque, produção
- Exemplos de dashboards profissionais

---

### **AULA 7: DASHBOARDS E INTEGRAÇÃO (4h)**

**Tópicos:** Conceitos de Dashboards, Design, Criação Prática e Interatividade

#### Conteúdo
- Conceitos de dashboard e painéis executivos
- Princípios de design eficiente de dashboards
- Elementos de um dashboard: KPIs, gráficos, indicadores
- Hierarquia visual e organização de componentes
- Cores e elementos para comunicação efetiva
- Integração de gráficos e tabelas dinâmicas
- Filtros segmentadores para interatividade
- Apresentação ao público executivo

#### Atividades Práticas
1. Planejar um dashboard executivo para gestão de materiais
2. Criar dashboard completo com dados reais integrados
3. Implementar filtros segmentadores que atualizam múltiplos gráficos
4. Demonstrar interatividade e facilidade de uso

#### Recursos
- Excel com múltiplas abas e dados consolidados
- Exemplos de dashboards de empresas
- Dados integrados de 12 meses operacionais

---

## 3. AULA 8: AVALIAÇÃO INTEGRADA (4h)

### **Avaliação Objetiva (2 horas)**

**Formato:** Prova escrita com questões de múltipla escolha e dissertativas

**Conteúdo avaliado:**
- Conceitos matemáticos e estatísticos (Aulas 1-2)
- Funções e fórmulas do Excel (Aulas 3-6)
- Criação de visualizações e dashboards (Aulas 6-7)

**Critérios de avaliação:**
- Compreensão de conceitos: 40%
- Aplicação prática: 40%
- Comunicação clara: 20%

**Nota mínima para aprovação:** 7,0

---

### **Avaliação Prática (2 horas)**

**Formato:** Desenvolvimento prático de projeto integrado com apresentação

**Projeto:** Desenvolvimento de análise de dados com criação de dashboard

**Descrição:**
Os alunos deverão:
1. Receber um conjunto de dados brutos (vendas, estoque ou RH — 12 meses)
2. Realizar análises estatísticas (média, mediana, desvio padrão)
3. Criar fórmulas e funções para cálculos (PROCV, IF aninhada, SOMASE)
4. Desenvolver tabelas dinâmicas para resumos automáticos
5. Criar um dashboard executivo com gráficos e KPIs
6. Apresentar resultados e conclusões em 10-15 minutos

**Pontuação:**
- Qualidade da análise: 30%
- Precisão dos cálculos: 30%
- Design e apresentação visual: 20%
- Apresentação oral: 20%

**Nota mínima para aprovação:** 7,0
