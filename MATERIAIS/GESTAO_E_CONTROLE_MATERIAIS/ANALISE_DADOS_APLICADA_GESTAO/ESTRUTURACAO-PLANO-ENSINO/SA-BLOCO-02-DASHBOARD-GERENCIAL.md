## Situação/Contexto

Uma empresa do setor de gestão de materiais possui base de dados grande com informações de estoque, vendas, custos e performance de fornecedores dos últimos 12 meses. A diretoria necessita de ferramenta visual que permita acompanhar KPIs (indicadores-chave) em tempo real, identificar tendências operacionais, detectar anomalias rapidamente e comparar performance entre períodos. Relatórios estáticos em PDF não atendem mais a necessidade de análise ágil; é preciso dashboard interativo que permita drill-down, filtros dinâmicos e múltiplas perspectivas de análise.

A equipe deve dominar funções avançadas do Excel (PROCV, SE aninhada, SOMASE), construir tabelas dinâmicas que resumam grandes volumes, criar gráficos de diferentes tipos, implementar validações e filtros, e finalmente consolidar tudo em dashboard profissional que comunique insights de forma clara para executivos e operadores.

---

## Desafio Integrador

Você recebe dataset completo de 12 meses de operações (estoque, vendas, custos, fornecedores). Sua tarefa é criar análise avançada e dashboard executivo que permita:

1. **Funções Avançadas de Análise:** Implemente PROCV para cruzar dados de produtos com fornecedores. Crie SE aninhadas para classificação ABC de materiais por valor. Utilize SOMASE para somar custos por categoria. Implemente tratamento de erros com IFERROR para garantir robustez.

2. **Tabelas Dinâmicas para Resumo:** Construa tabelas dinâmicas que resumam vendas por categoria, período e fornecedor. Crie agregações de custo por departamento. Implemente filtros dinâmicos que permitam análise de perspectivas diferentes (por período, por fornecedor, por categoria).

3. **Gráficos e Visualizações:** Crie gráficos de colunas para comparação de vendas entre períodos. Implemente gráficos de linhas para mostrar tendências de custos. Use gráficos de pizza para composição de estoque. Crie scatter plot para correlação entre quantidade e custo. Formatar todos com cores corporativas e títulos claros.

4. **Dashboard Integrado:** Consolide gráficos, tabelas dinâmicas e KPIs principais em um único dashboard. Implemente filtros segmentadores que atualizam todos os gráficos simultaneamente. Adicione campos de KPI principais (rotatividade de estoque, custo médio, nível de serviço). Organize visualmente para facilitar compreensão rápida.

5. **Apresentação Executiva:** Prepare apresentação do dashboard para diretoria explicando cada elemento, como interpretar dados, quais decisões cada KPI suporta. Demonstre interatividade dos filtros. Apresente insights descobertos (tendências, anomalias, oportunidades de melhoria). Explique como usar dashboard para decisões operacionais diárias.
