# SA BLOCO 01 — Análise Matemática e Estruturação de Dados em Excel

**Carga horária:** 16 horas (4 aulas de 4h)  
**Público:** Técnico em Gestão e Controle de Materiais  
**Capacidades:** Aplicar operações matemáticas e estruturar dados em Excel

---

**Contexto:** Preparar profissional para transformar dados brutos em informações estruturadas  
**Foco:** Operações matemáticas + Excel básico  
**Nome sugerido:** "SA 01 ESTRUTURACAO-DADOS-GESTAO" ou "SA-ANALISE-MATEMATICA-PROFISSIONAL"

---

## Situação/Contexto

Um setor de gestão de materiais recebeu dados brutos de operações do trimestre anterior: anotações de quantidades de estoque, informações de custos desorganizadas, registros de vendas em formatos diferentes, dados de produção em documentos múltiplos. A equipe necessita consolidar, organizar, analisar e comunicar esses dados através de operações matemáticas precisas e planilhas estruturadas que possibilitem tomada de decisão rápida.

Além de dados desorganizados, há necessidade de cálculos que envolvem proporções, percentuais, variações de custos e análises estatísticas. Os colaboradores precisam compreender os fundamentos matemáticos aplicados à gestão, dominar a interface do Excel e criar planilhas profissionais que comuniquem informações críticas para a operação.

---

## Desafio Integrador

Você recebe um conjunto de dados brutos (anotações de estoque, custos, vendas, produção) relacionados a uma semana operacional de gestão de materiais. Sua tarefa é consolidar, processar e comunicar esses dados através de:

1. **Análise Matemática:** Realize cálculos de proporção e percentual de rotatividade de estoque. Calcule variações de custos de um período para outro usando regra de três. Determine margem de contribuição de produtos. Interprete desvios padrão para identificar anomalias operacionais.

2. **Consolidação de Dados:** Organize informações brutas em planilha Excel estruturada com linhas, colunas bem nomeadas e cabeçalhos claros. Implemente formatação de moedas para dados financeiros, percentuais para variações e datas padronizadas. Congele painéis para facilitar visualização e navegação.

3. **Aplicação de Fórmulas Básicas:** Utilize SUM para totalizações (custo total, quantidade total), AVERAGE para médias de estoque e custos unitários, COUNT para contar registros e IF para criar classificações condicionais (produtos em falta, custos acima de limite, estoque crítico).

4. **Análise Estatística:** Calcule medidas estatísticas (média, mediana, moda, desvio padrão) de dados operacionais. Identifique outliers que indicam anomalias. Interprete correlações entre variáveis (quantidade × custo, por exemplo).

5. **Apresentação Profissional:** Transforme dados organizados em relatório visual profissional utilizando formatação condicional para destacar valores críticos. Crie documento formatado em Excel pronto para apresentação a gestores, com dados organizados logicamente e visuais claros.
