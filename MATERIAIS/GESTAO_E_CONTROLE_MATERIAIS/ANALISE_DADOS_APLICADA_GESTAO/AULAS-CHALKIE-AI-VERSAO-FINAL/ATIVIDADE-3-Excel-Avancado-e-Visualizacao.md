## Lista de Atividades

1. ⬜ Implementar PROCV para buscar valores em tabelas de referência

2. ⬜ Usar PROCV com referências absolutas para manter tabela de consulta estável

3. ⬜ Aplicar PROCH para buscas horizontais em bases estruturadas em linhas

4. ⬜ Combinar ÍNDICE e CORRESPONDÊNCIA para buscas flexíveis em qualquer direção

5. ⬜ Anular erros de busca utilizando função SEERRO

6. ⬜ Construir lógicas condicionais aninhadas com múltiplos SE

7. ⬜ Utilizar SOMASE para somar vendas por categoria específica

8. ⬜ Implementar CONT.SE para contar ocorrências em bases gerenciais

9. ⬜ Criar Tabelas Dinâmicas para resumir dados por múltiplas dimensões

10. ⬜ Aplicar segmentadores (slicers) para filtros visuais interativos

11. ⬜ Conectar gráficos dinâmicos às Tabelas Dinâmicas para atualização automática

12. ⬜ Estruturar relatórios de vendas consolidados por região e período

13. ⬜ Analisar KPIs (faturamento, margem, quantidade) em painéis estruturados

14. ⬜ Comparar períodos (YoY, MoM) para identificar tendências de performance
