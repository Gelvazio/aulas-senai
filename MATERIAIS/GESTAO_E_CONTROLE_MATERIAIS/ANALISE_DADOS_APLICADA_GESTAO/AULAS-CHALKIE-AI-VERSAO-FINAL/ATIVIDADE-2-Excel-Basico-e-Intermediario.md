# Atividades - Excel Básico e Intermediário para Gestão

**Baseado em:** 2-Excel-Basico-e-Intermediario.md

---

## Lista de Atividades

1. ⬜ Navegar pela interface do Excel e identificar guias, faixa de opções e caixa de nome

2. ⬜ Criar e formatar planilhas com cabeçalhos em destaque e bordas estruturadas

3. ⬜ Executar operações matemáticas básicas (+, -, *, /, ^) em fórmulas

4. ⬜ Aplicar ordem de precedência matemática corretamente em expressões complexas

5. ⬜ Usar referências relativas (A1) e absolutas ($A$1) em fórmulas expansíveis

6. ⬜ Construir fórmulas SOMA para consolidar valores de vendas e receitas

7. ⬜ Implementar fórmula MÉDIA para calcular tickets médios de vendas

8. ⬜ Usar função SE para lógica condicional simples (verdadeiro/falso)

9. ⬜ Aplicar CONT.SE para contar células que atendem critérios específicos

10. ⬜ Implementar SOMASE para somar valores sob condições múltiplas

11. ⬜ Validar dados de entrada para evitar erros operacionais

12. ⬜ Congelar painéis para facilitar navegação em planilhas grandes

13. ⬜ Formatar células como moeda, percentual e data conforme o contexto

14. ⬜ Criar gráficos básicos (colunas e linhas) para visualizar tendências
