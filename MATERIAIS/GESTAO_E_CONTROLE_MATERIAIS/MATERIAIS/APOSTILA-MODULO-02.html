Introdução

Excel é a ferramenta fundamental nas operações administrativas modernas. Este módulo ensina desde o básico até funções avançadas para análise de dados profissional.

1. Interface e Fundamentos

1.1 Interface do Excel

ElementoDescrição
Barra de TítuloNome do arquivo e aplicativo
Fita (Ribbon)Menus e ferramentas organizadas por abas
CélulasIntersecção de linha (números) e coluna (letras)
Barra de FórmulasMostra conteúdo da célula selecionada

1.2 Navegação Básica

  • Clique: Selecionar célula
  • Setas: Mover entre células
  • Ctrl+Home: Ir para célula A1
  • Ctrl+End: Ir para última célula com dados
  • Ctrl+F: Buscar texto

1.3 Operações Básicas

Inserir dados: Digite na célula e pressione Enter

Copiar: Ctrl+C | Colar: Ctrl+V | Cortar: Ctrl+X

Desfazer: Ctrl+Z | Refazer: Ctrl+Y

1.4 Formatação

  • Negrito: Ctrl+B
  • Itálico: Ctrl+I
  • Cor de Fundo: Abas Home > Fill Color
  • Bordas: Home > Borders
  • Formato de Número: Clique direito > Format Cells > Number

2. Operações Matemáticas Básicas

2.1 Fórmulas Simples

OperaçãoFórmulaExemplo
Soma=SUM(A1:A5)=SUM(10,20,30) = 60
Subtração=A1-B1=100-30 = 70
Multiplicação=A1*B1=5*10 = 50

3. Funções Avançadas

3.1 PROCV (Busca Vertical)

=PROCV(valor_procurado, tabela, número_coluna, [intervalo_aproximado])
Uso: Buscar nome de produto pelo código

Exemplo: =PROCV("P001", A:D, 2, FALSE)

Busca "P001" na coluna A e retorna valor da coluna 2 (B)

3.2 Função SE (Condicional)

=SE(condição, valor_se_verdadeiro, valor_se_falso)
Uso: Classificar vendas em categorias

Exemplo: =SE(A1>1000, "Alto", "Baixo")

Se valor em A1 > 1000, escreve "Alto", senão "Baixo"

3.3 CONTAR.SE

=CONTAR.SE(intervalo, critério)
Uso: Contar quantos valores atendem critério

Exemplo: =CONTAR.SE(A1:A100, ">100")

Conta quantas células em A1:A100 têm valor maior que 100

3.4 IFERROR (Tratamento de Erros)

=IFERROR(fórmula, valor_se_erro)
Uso: Evitar exibir erro #DIV/0!

Exemplo: =IFERROR(A1/B1, 0)

Se B1 é zero (erro), mostra 0 em vez de erro

4. Tabelas Dinâmicas

4.1 Conceito

Tabela dinâmica resume dados automaticamente. Reorganize informações rapidamente sem alterar dados originais.

4.2 Criar Tabela Dinâmica

  1. Selecione dados (incluindo cabeçalho)
  2. Insert > Pivot Table
  3. Escolha novo local ou planilha existente
  4. Arraste campos para: Rows, Columns, Values, Filters
Dica: Linhas = informação a agrupar | Colunas = para comparação | Valores = o que sumarizar (SUM, COUNT, AVERAGE, etc)

4.3 Campos Principais

CampoDescrição
RowsDados aparecem em linhas
ColumnsDados aparecem em colunas
ValuesValores a resumir (SUM, COUNT, etc)
FiltersFiltrar tabela dinâmica

5. Filtros

5.1 AutoFiltro

  1. Selecione cabeçalho de coluna
  2. Data > AutoFilter
  3. Clique seta ao lado do nome da coluna
  4. Escolha valores a exibir

5.2 Filtro Avançado

Críterios múltiplos: combinar várias condições (AND/OR)

Exemplo: Mostrar apenas vendas > R$1000 E na região "Sul"

Data > Advanced > Defina critérios em colunas separadas

6. Validação e Proteção de Dados

6.1 Validação de Dados

  1. Selecione células
  2. Data > Data Validation
  3. Escolha tipo: Whole Number, List, Date, etc
  4. Defina critério (ex: entre 0 e 100)
Uso: Lista suspensa com opções pré-definidas

Type: List | Source: Alto,Médio,Baixo

6.2 Proteção de Células

  1. Format > Cells > Protection (marque "Locked")
  2. Review > Protect Sheet
  3. Defina senha (opcional)
  4. Usuários não conseguem editar células protegidas

7. Gráficos e Dashboards

7.1 Criar Gráfico

  1. Selecione dados (incluindo cabeçalho)
  2. Insert > Chart
  3. Escolha tipo: Column, Line, Pie, etc
  4. Customize título, eixos, legenda

7.2 Tipos de Gráfico

TipoUsoExemplo
Coluna/BarraComparação entre categoriasVendas por região
LinhaTendência ao longo do tempoEvolução mensal
PizzaProporção de partes% por categoria
DispersãoRelacionar duas variáveisPreço vs Quantidade

7.3 Dashboard

Painel visual que sumariza informações principais em um único lugar.

Elementos: KPIs (números principais), gráficos analíticos, tabelas, filtros interativos

Exercícios Resolvidos

Exercício 1: Fórmula Simples

Problema: Criar coluna com total de vendas (Quantidade × Preço Unitário)

Solução:

Em célula D1: =B1*C1 (se B=Quantidade, C=Preço)

Copie fórmula para outras linhas (Ctrl+C, selecione, Ctrl+V)

Exercício 2: PROCV

Problema: Trazer nome do produto usando código em coluna A, tendo tabela de referência em colunas F:G

Solução:

Em célula B1: =PROCV(A1, F:G, 2, FALSE)

Copie para outras linhas

Exercício 3: Função SE

Problema: Classificar produtos como "Em falta" se quantidade < 10, senão "Ok"

Solução:

Em célula C1: =SE(A1<10, "Em falta", "Ok")

Copie para outras linhas
