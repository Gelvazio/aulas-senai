# Criar Tabelas `aulas` e `material` - Estrutura Relacional

**Data de Criação:** 2026-09-05  
**Status Geral:** ⬜ Planejado  
**Prioridade:** Crítica

---

## 📌 Objetivo

Criar duas tabelas para estruturar melhor os dados:

1. **Tabela `aulas`** — Armazena aulas de cada matéria
   - Substitui armazenamento JSONB em `materia.aulas`
   - FK para materia, curso
   - Dados estruturados e normalizados

2. **Tabela `material`** — Centraliza vínculos entre:
   - **Material** ↔ **Aula** (qual aula usa este material)
   - **Material** ↔ **Matéria** (qual matéria contém este material)
   - **Material** ↔ **Curso** (qual curso o material pertence)
   - **Material** ↔ **Tipo** (atividade, avaliação, recurso, etc.)

---

## 📋 Escopo

### Novas Tabelas
1. **`material`** — Tabela central de materiais
2. **`tipo_material`** — Tipos de materiais (atividade, avaliação, recurso, etc.)

### Relacionamentos
- `material.tipo_material_id` → `tipo_material.id`
- `material.aula_id` → materia.aulas (via JSONB) — ou coluna nova
- `material.materia_id` → `materia.id`
- `material.curso_id` → `curso.id`

### Passo 3: Migrar Atividades para Material (Exemplo)
```sql
-- Inserir atividades como materiais
INSERT INTO public.material (
  nome, descricao, tipo_material_id, 
  materia_id, curso_id, 
  ativo, ordem, criado_em
)
SELECT
  a.descricao AS nome,
  CONCAT('Data início: ', a.datainicio, ' | Data fim: ', a.datafim) AS descricao,
  (SELECT id FROM public.tipo_material WHERE nome = 'Atividade') AS tipo_material_id,
  a.materiaid AS materia_id,
  c.id AS curso_id,
  CASE WHEN a.ativo = 1 THEN true ELSE false END AS ativo,
  0 AS ordem,
  now() AS criado_em
FROM public.atividade a
JOIN public.materia m ON m.id = a.materiaid
JOIN public.cursomateria cm ON cm.materiaid = m.id
JOIN public.curso c ON c.id = cm.cursoid
WHERE NOT EXISTS (
  SELECT 1 FROM public.material
  WHERE nome = a.descricao AND materia_id = a.materiaid
)
ON CONFLICT DO NOTHING;
```

### Passo 4: Migrar Avaliações para Material (Exemplo)
```sql
-- Inserir avaliações como materiais
INSERT INTO public.material (
  nome, descricao, tipo_material_id,
  materia_id, curso_id,
  ativo, ordem, criado_em
)
SELECT
  av.titulo AS nome,
  CONCAT('Número: ', av.numero, ' | Data: ', av.data_aplicacao, ' | Status: ', av.status) AS descricao,
  (SELECT id FROM public.tipo_material WHERE nome = 'Avaliação') AS tipo_material_id,
  av.materia_id,
  c.id AS curso_id,
  true AS ativo,
  av.numero AS ordem,
  av.created_at AS criado_em
FROM public.avaliacao av
JOIN public.materia m ON m.id = av.materia_id
JOIN public.cursomateria cm ON cm.materiaid = m.id
JOIN public.curso c ON c.id = cm.cursoid
WHERE NOT EXISTS (
  SELECT 1 FROM public.material
  WHERE nome = av.titulo AND materia_id = av.materia_id
)
ON CONFLICT DO NOTHING;
```
