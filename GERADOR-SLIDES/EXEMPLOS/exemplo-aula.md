# Bloco 1 — Fundamentos

## História da Computação

- Ábaco, por volta de 2000 a.C.: primeiro instrumento de cálculo
- Pascalina, 1642: somas e subtrações mecânicas
- Tear de Jacquard, 1801: nasce a ideia de programa
- Máquina Analítica, 1837: o primeiro projeto programável
- ENIAC, 1946: o primeiro eletrônico de grande porte
- Microprocessador, 1971: o computador cabe em uma mesa

::: notas
Não decorar datas. O ponto é perceber que cada avanço resolveu um problema
real de trabalho.
:::

## Linha do Tempo — Marcos

| Ano | Marco | O que resolveu |
| --- | --- | --- |
| 1946 | ENIAC | Primeiro eletrônico de grande porte |
| 1947 | Transistor | Menor, mais rápido, mais barato |
| 1971 | Intel 4004 | Microprocessador |
| 1983 | Internet | Conexão global |
| 2007 | Smartphone | O computador no bolso |

## As Gerações de Computadores

- Primeira geração, 1940 a 1955: válvulas
- Segunda geração, 1955 a 1964: transistores
- Terceira geração, 1964 a 1971: circuitos integrados
- Quarta geração, 1971 até hoje: microprocessadores
- Quinta geração, em curso: nuvem e inteligência artificial

> O ENIAC ocupava 180 m² e fazia 5.000 somas por segundo. Um celular comum faz bilhões.

## Hardware e Software

### Hardware

- Tudo o que se pode tocar
- Gabinete, monitor, teclado
- Placa-mãe e processador
- Memória e armazenamento

### Software

- Tudo o que se usa e não se toca
- Sistema operacional
- Programas e aplicativos
- Arquivos e instruções

## Analogia do Trabalho

> O hardware é a máquina da oficina. O software é o manual que diz o que ela deve fazer.

- Sem manual, a máquina não produz nada útil
- Sem máquina, o manual é apenas papel
- Os dois só têm valor juntos

# Bloco 2 — Operando o Computador

## Componentes Internos

- Processador: executa as instruções
- Memória RAM: área de trabalho temporária
- Disco SSD ou HD: armazenamento permanente
- Placa-mãe: conecta todos os componentes
- Fonte: converte e distribui a energia

## Periféricos

### Entrada

- Teclado
- Mouse
- Scanner
- Microfone

### Saída

- Monitor
- Impressora
- Caixa de som
- Projetor

## Mouse — Os Quatro Gestos

- Clique simples: seleciona um item
- Clique duplo: abre o item selecionado
- Clique direito: abre o menu de opções
- Arrastar e soltar: move o item de lugar

::: notas
Fazer a demonstração no projetor antes de liberar a prática individual.
:::

## Teclado — Atalhos Essenciais

| Atalho | Função |
| --- | --- |
| Ctrl + C | Copiar |
| Ctrl + V | Colar |
| Ctrl + X | Recortar |
| Ctrl + Z | Desfazer |
| Ctrl + S | Salvar |

> Quem domina cinco atalhos trabalha mais rápido que quem domina cinquenta menus.

## Área de Trabalho

- Ícones: atalhos para programas e arquivos
- Barra de tarefas: o que está aberto agora
- Menu Iniciar: onde tudo começa
- Lixeira: o que foi excluído mas ainda pode voltar

## Pastas e Arquivos

- Pasta organiza; arquivo guarda o conteúdo
- A estrutura é uma árvore, do disco até o arquivo
- Caminho é o endereço completo do arquivo
- A extensão diz qual programa abre o arquivo

> Nome de arquivo sem padrão é arquivo perdido. Use data e assunto.

# Bloco 3 — Prática e Fechamento

## Atividade 1 — Caça aos Componentes

- Em duplas, listar cinco itens de hardware visíveis na bancada
- Classificar cada um como entrada, saída ou processamento
- Apontar qual software cada item precisa para funcionar
- Apresentar as conclusões em dois minutos

## Atividade 2 — Organização Digital

- Criar a pasta CURSO-TIC na área de trabalho
- Criar dentro dela as subpastas AULAS, ATIVIDADES e PROVAS
- Salvar um arquivo de teste em ATIVIDADES
- Renomear seguindo o padrão data-assunto

## Avaliação Formativa

- Observação da autonomia no uso do mouse e do teclado
- Consistência da estrutura de pastas criada
- Participação nas discussões em dupla
- Clareza ao explicar a diferença entre hardware e software

## Encerramento

- Hardware é corpo, software é instrução
- A organização de arquivos é competência profissional
- Atalhos economizam horas ao longo do mês
