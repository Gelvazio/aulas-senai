Como usar o Gerador de Aulas:
📌 Passo 1: Prepare sua ementa em formato Markdown com a estrutura obrigatória
📌 Passo 2: Acesse a aba "Upload" e selecione o arquivo
📌 Passo 3: Configure os parâmetros (UC, carga horária, etc)
📌 Passo 4: Clique em "Gerar Aulas" e aguarde o processamento
Estrutura obrigatória da ementa:
  • ✓ Identificação da UC (nome, carga horária)
  • ✓ Objetivo Geral
  • ✓ Capacidades Básicas (3-6)
  • ✓ Domínios de Conhecimento (4.1, 4.2, 4.3...)
  • ✓ Competência Integradora
  • ✓ Capacidades Socioemocionais

💡 Veja exemplo: sistema/INTRODUCAO_TIC/EMENTA-INTRODUCAO-TENOLOGIA-INFORMACAO.md

Formatos aceitos: Markdown (.md) ou PDF estruturado
