Como usar o Gerador de Aulas:
📌 Passo 1: Prepare sua ementa em formato Markdown com a estrutura obrigatória
📌 Passo 2: Acesse a aba "Upload" e selecione o arquivo
📌 Passo 3: Configure os parâmetros (UC, carga horária, etc)
📌 Passo 4: Clique em "Gerar Aulas" e aguarde o processamento
Estrutura obrigatória da ementa:
  • ✓ Identificação da UC (nome, carga horária)
  • ✓ Objetivo Geral
  • ✓ Capacidades Básicas (3-6)
  • ✓ Domínios de Conhecimento (4.1, 4.2, 4.3...)
  • ✓ Competência Integradora
  • ✓ Capacidades Socioemocionais

💡 Veja exemplo: sistema/INTRODUCAO_TIC/EMENTA-INTRODUCAO-TENOLOGIA-INFORMACAO.md

Formatos aceitos: Markdown (.md) ou PDF estruturado

✅ Padrão Obrigatório de Infograficos
⚠️ Elementos Obrigatórios:
1️⃣ Cabeçalho Visual
  • ✓ Título principal em branco (GRANDE, legível)
  • ✓ Subtítulo em dourado/ouro (2-3 palavras-chave)
  • ✓ Ícone representativo do tema
  • ✓ Star/destaque visual (canto superior)
2️⃣ Estrutura de Conteúdo
  • ✓ Mínimo 6 seções numeradas (1, 2, 3, ...)
  • ✓ Cada seção com cor DIFERENTE (paleta diversa)
  • ✓ Cada seção com ícone representativo
  • ✓ Hierarquia clara: começo → desenvolvimento → fim
3️⃣ Design Visual
  • ✓ Fundo escuro (azul, cinza ou preto)
  • ✓ Texto branco/claro em fundo escuro
  • ✓ Cores vibrantes para sections
  • ✓ Espaço em branco importante (sem poluição)
4️⃣ Rodapé/Conclusão
  • ✓ "Regra de Ouro" ou insight principal destacado
  • ✓ Próximos passos ou call-to-action
  • ✓ Branding/identificação (opcional)
