## Critérios de Qualidade — Resumo Consolidado

### Avaliações Objetivas (7 Critérios)

1. **Quantidade Mínima** — Alinhada com carga horária (1–3 avaliações)
2. **Aplicação Comprovada** — Registro no diário de classe ⚠️ Eliminatório
3. **Quantidade de Questões** — Mínimo 3 questões (4–5 alternativas)
4. **Nível Cognitivo** — Avalia capacidades no nível cognitivo correto
5. **Contextualização** — Situações-problema do mundo do trabalho
6. **Comando do Item** — Conforme Apostila de Elaboração de Itens
7. **Alternativas Plausíveis** — Respostas coerentes e atraentes

**Nota Importante:** Para atender critérios 4–7, pelo menos **3 itens** da prova devem estar em perfeita conformidade.

### Avaliações Práticas (7 Critérios)

1. **Aplicação Comprovada** — Registro no diário de classe ⚠️ Eliminatório
2. **Avaliação de Capacidades** — Todas as capacidades listadas são avaliadas
3. **Contextualização** — Situação-problema alinhada com mundo do trabalho
4. **Desafio Sem Roteiro** — Não pode ser passo-a-passo
5. **Resultados Esperados** — Atividades + Evidências + Entregas claras
6. **Critérios de Avaliação** — Um critério mínimo por atividade
7. **Alinhamento** — Critérios relacionados com capacidades avaliadas

## Fluxo de Uso

### Para Criar Prova Objetiva
1. Verificar quantidade mínima (tabela no Checklist)
2. Revisar 7 critérios do Checklist
3. Usar exemplo do Modelo (Eletromecânica)
4. Registrar no SGN quando aplicada

### Para Criar Prova Prática
1. Usar Template como base
2. Consultar Modelo (Eletrotécnica) ou Prova Prática (3)
3. Seguir 7 critérios do Checklist
4. Garantir: contexto, desafio, entregas, anexos, verificação

### Para Criar Rubricas
1. Identificar capacidades socioemocionais do curso
2. Usar PROMPT como guia
3. Adaptar para IA (substituir placeholders)
4. Receber tabela 6 colunas (Competência | Capacidade | Nível 1–4)
