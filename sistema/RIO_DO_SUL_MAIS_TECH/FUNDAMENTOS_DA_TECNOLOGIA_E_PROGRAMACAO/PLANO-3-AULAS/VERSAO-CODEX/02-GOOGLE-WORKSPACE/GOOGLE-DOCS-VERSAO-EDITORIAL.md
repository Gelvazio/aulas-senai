# GOOGLE DOCS

**Editor de Texto • Colaboração em Nuvem ⭐**

---

## 1. Visão Geral

**Tipo:** Processador de texto online

**Acesso:** Browser + app desktop

**Custo:** Gratuito com Google Account

**Sync:** Google Drive (15GB grátis)

☁️ Nuvem

🔄 Colaboração

## 2. Recursos Principais

✓ Formatação básica (fontes, cores, estilos)

✓ Tabelas simples com mesclagem

✓ Cabeçalhos e estrutura

✓ Imagens e comentários

✓ Share link automático

## 3. Colaboração Real-time

✓ Múltiplos usuários editam juntos

✓ Histórico de versões (automático)

✓ Comentários com thread (resolvíveis)

✓ Sugestões de mudanças

✓ Notificações de atividade

## 4. Templates

• Carta formal

• Relatório

• Proposta

• Currículo

• 95+ modelos

## 5. Integração

✓ Google Sheets, Slides, Forms

✓ Google Drive (storage nativo)

✓ Gmail compartilhamento

✓ Add-ons (Grammarly, etc.)

✓ API para automação

## 9. Acessibilidade Offline

✓ Modo offline (chrome://apps)

✓ Edição sem internet

✓ Sync ao voltar online

✓ Cópia local sincronizada

⚠️ Colaboração offline limitada

#### ✅ Caso de Uso Ideal

Documentos colaborativos de equipe

Projetos dinâmicos que mudam frequentemente

Documentos de acesso remoto

Histórico de versões ilimitado

**Ponto Forte:** Colaboração sem paralelo — múltiplos editores em tempo real com histórico completo

**Limitação:** Formatação avançada (índice automático, notas de rodapé) comparada ao Word
