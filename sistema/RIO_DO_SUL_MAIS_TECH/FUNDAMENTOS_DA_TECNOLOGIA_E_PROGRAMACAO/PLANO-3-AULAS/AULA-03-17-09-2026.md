## Conteúdo Programático

### 1. Introdução a Apresentações (15 min)

**O que é uma apresentação?** Sequência de slides para comunicar ideias, dados ou conhecimento a uma audiência.

**Usos comuns:**
- Apresentações escolares
- Pitches de negócios
- Seminários e palestras
- Treinamentos
- Reuniões profissionais

**Estrutura típica:**
```
Slide 1  → Capa (Título, autor, data)
Slide 2  → Índice (o que será apresentado)
Slide 3-N → Conteúdo (tópicos principais)
Slide N+1 → Conclusão/Resumo
Slide N+2 → Obrigado/Perguntas
```

**Diferenças — PowerPoint vs. Google Slides:**

| Aspecto | PowerPoint | Google Slides |
|---|---|---|
| **Acesso** | Instalado no PC | Na nuvem (web) |
| **Custo** | Pago (Office 365) | Gratuito |
| **Arquivo** | .pptx, .ppt | Google Slides, exportar .pptx |
| **Colaboração** | Compartilhamento de arquivo | Edição em tempo real |
| **Temas** | Muitos temas integrados | Biblioteca de temas |
| **Apresentação** | Modo apresentador (Slide Show) | Modo apresentação web |
| **Offline** | Sim | Não |
| **Recursos 3D** | Sim (avançado) | Não |

---

### 2. PowerPoint — Interface e Estrutura (20 min)

**Componentes da Tela:**
- **Slide Pane (esquerda):** Lista de slides
- **Editor Central:** Editar slide atual
- **Ribbon (topo):** Abas de ferramentas (Home, Insert, Design, Transitions, etc.)
- **Notes Panel (embaixo):** Anotações para o apresentador

**Criar Nova Apresentação:**
- Arquivo > Novo
- Escolher template/tema
- Ou começar em branco

**Componentes do Slide:**
- **Título:** Texto principal (geralmente topo)
- **Corpo:** Conteúdo (bullets, texto, elementos)
- **Fundo:** Cor ou imagem de fundo
- **Espaço em branco:** Respiro visual

**Tipos de Slides:**
- Título (capa)
- Título e Conteúdo (bullets)
- Título Apenas
- Em Branco (liberdade total)
- Comparação (2 colunas)
- Seção (transição entre temas)

---

### 3. Formatação e Design no PowerPoint (20 min)

**Tema vs. Design:**
- **Tema:** Conjunto integrado de cores, fontes, espaçamento
- **Personalização:** Mudar cores, fontes individuais

**Cores e Paleta:**
- Usar paleta coordenada (não mais de 3-4 cores)
- Contraste: texto claro em fundo escuro (ou vice-versa)
- Cores com significado: Verde (ok), Vermelho (atenção), Azul (confiança)

**Tipografia (Fontes):**
- Título: Fonte maior, bold, chamativa
- Corpo: Fonte legível, tamanho adequado (mínimo 18pt)
- Máximo 2 tipos de fonte por slide (1 título + 1 corpo)
- Evitar fontes muito decorativas

**Exemplo de Hierarquia:**
```
TÍTULO DO SLIDE (40pt, Negrito, Azul)

Tópico Principal (28pt, Negrito, Preto)
  • Ponto 1 (20pt, Normal)
  • Ponto 2 (20pt, Normal)
  • Ponto 3 (20pt, Normal)
```

**Boas Práticas de Design:**
- ✓ Menos texto, mais visuais
- ✓ Uma ideia por slide
- ✓ Alinhamento consistente
- ✓ Espaço em branco (não preencher tudo)
- ✓ Imagens de alta qualidade
- ✗ Não use muitos efeitos (fica poluído)
- ✗ Não leia direto do slide (fale com audiência)

### 4. Inserir Elementos Multimídia (15 min)

**Imagens:**
- Insert > Pictures (do computador)
- Insert > Pictures > Stock Images (do Bing)
- Redimensionar arrastando canto
- Aplicar estilos/filtros

**Tabelas:**
- Insert > Table
- Especificar linhas e colunas
- Preencher dados
- Formatar com cores

**Gráficos:**
- Insert > Chart
- Escolher tipo (coluna, pizza, linha)
- Editar dados
- Personalizar cores

**Formas:**
- Insert > Shapes
- Adicionar caixas de texto
- Criar diagramas

**Vídeos/Áudio:**
- Insert > Video
- Incorporar do YouTube
- Adicionar som de fundo (cuidado com volume)

---

### 5. Animações e Transições (15 min)

**Transições entre Slides:**
- Mudam como um slide entra/sai
- Exemplos: Fade, Push, Wipe, Zoom
- Usar consistentemente (mesma transição)
- Velocidade: Normal (0.5s) ou Rápida (0.25s)

**Animações de Objeto:**
- Movem elementos dentro do slide
- Entrada: Aparecer, Deslizar, Crescer
- Saída: Desaparecer, Sumir
- Ênfase: Destacar, Girar, Mudar cor

**Quando usar:**
- ✓ Para realçar pontos importantes
- ✓ Revelar informações gradualmente
- ✗ Não exagere (fica cansativo)
- ✗ Evitar piscas/zoom extremo

---

### 6. Google Slides — Colaboração (10 min)

**Acesso:**
- docs.google.com/presentation
- Login com conta Google

**Interface:** Similar ao PowerPoint, mas simplificada

**Vantagens Colaborativas:**
- ✓ Múltiplos usuários editando ao mesmo tempo
- ✓ Ver cursor/seleção dos outros usuários
- ✓ Comentários em slides
- ✓ Histórico de versões
- ✓ Modo apresentação diretamente (sem baixar)

**Compartilhamento:**
- Botão Share
- Permissões: Visualizar, Comentar, Editar
- Notificar via email

**Apresentar diretamente:**
- Botão "Present" (canto direito)
- Apresentar direto da web
- Notas do apresentador visíveis só para você

---

### 7. Dicas para Apresentação Eficaz (5 min)

**Antes de Apresentar:**
- ✓ Ensaiar pelo menos 2 vezes
- ✓ Conhecer o espaço/equipamento
- ✓ Testar projetor/áudio
- ✓ Imprimir slides (cópias para audiência)

**Durante a Apresentação:**
- ✓ Falar com clareza (não monótono)
- ✓ Fazer contato visual
- ✓ Não ficar de costas (virando para tela)
- ✓ Deixar tempo para perguntas
- ✓ Controlar ritmo (rápido demais = confunde)

**Nervosismo:**
- Respirar fundo antes
- Pensar que audiência quer que você tenha sucesso
- Conhecer o assunto reduz nervosismo

## Atividades Práticas

### Atividade 1: Criar Apresentação sobre Tema Livre no PowerPoint (40 min)

**Tarefa:** Apresentação "Meu Hobby/Paixão" (6-8 slides)

**Estrutura Obrigatória:**

| Slide | Conteúdo | Requisito |
|---|---|---|
| 1 | Capa (Título, seu nome, data) | Imagem de fundo |
| 2 | Índice (o que vai falar) | Bullets |
| 3-5 | Desenvolvimento (3 pontos principais) | 1 imagem por slide |
| 6 | Gráfico ou tabela | Dados reais/fictícios |
| 7 | Conclusão/Aprendizado | Reflexão pessoal |
| 8 | Obrigado/Perguntas | Design limpo |

**Requisitos:**
- ✓ Tema consistente (cores, fontes)
- ✓ Mínimo 6 imagens
- ✓ 1 tabela ou gráfico
- ✓ Transições em alguns slides
- ✓ Sem poluição visual (máximo 3 cores)
- ✓ Texto legível (mínimo 18pt)

**Entrega:** Arquivo .pptx + Apresentação oral (3 min) para turma

### Atividade 2: Colaboração no Google Slides (30 min)

**Tarefa:** "Apresentação de Classe — Rio do Sul Mais Tech"

**Procedimento:**
1. Professor cria Google Slides vazio
2. Compartilha com toda turma (permissão editar)
3. Divide turma em 4 grupos:
   - Grupo 1: Capa + índice
   - Grupo 2: O que é Rio do Sul Mais Tech (3 slides)
   - Grupo 3: Nossos Aprendizados (2 slides + 1 gráfico)
   - Grupo 4: Conclusão + Fotos

4. Cada grupo edita seu slide simultaneamente (15 min)
5. Revisar apresentação completa (5 min)
6. Sugerir melhorias via comentários (5 min)
7. Ver histórico de versões (5 min)

**Aprendizado:** Colaboração em tempo real, evitar conflitos

### Atividade 3: Análise Crítica — "Apresentação Perfeita vs. Ruim" (20 min)

**Procedimento:**
1. Professor mostra 2 vídeos curtos de apresentações:
   - Exemplo RUIM: Muitas cores, fonte pequena, texto demais, transições excessivas
   - Exemplo BOM: Design limpo, imagens, comunicação clara

2. Turma discute:
   - "Quais foram os problemas da apresentação ruim?"
   - "O que tornou a apresentação boa eficaz?"
   - "Como você melhoraria a ruim?"

3. Listar checklist de boas práticas no quadro
