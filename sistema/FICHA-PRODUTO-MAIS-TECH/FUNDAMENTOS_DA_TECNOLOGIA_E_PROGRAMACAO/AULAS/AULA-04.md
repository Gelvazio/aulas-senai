### 2. Arquivos e Pastas (30 min)

**O que é arquivo?** Documento, imagem, vídeo, programa — dados armazenados com nome único.

**O que é pasta?** Recipiente que organiza arquivos (analogia: gaveta em uma escrivaninha).

**Extensões de arquivo (indicam tipo):**
- `.docx` → Documento Word
- `.pdf` → PDF
- `.xlsx` → Planilha Excel
- `.jpg` / `.png` → Imagens
- `.mp4` / `.avi` → Vídeos
- `.mp3` → Áudio
- `.exe` → Programa (Windows)

**Estrutura de Pastas — Hierarquia:**
```
C:\ (disco rígido)
├── Usuários
│   └── Seu Nome
│       ├── Documentos
│       ├── Downloads
│       ├── Imagens
│       └── Vídeos
├── Programas (Program Files)
└── Windows (Sistema)
```

---

### 3. Operações com Arquivos (30 min)

| Operação | Como fazer | Atalho |
|---|---|---|
| **Criar arquivo novo** | Clicar direito > Novo > Documento | — |
| **Criar pasta nova** | Clicar direito > Nova Pasta | — |
| **Copiar** | Clicar direito > Copiar ou Ctrl+C | Ctrl+C |
| **Colar** | Clicar direito > Colar ou Ctrl+V | Ctrl+V |
| **Recortar** | Clicar direito > Recortar ou Ctrl+X | Ctrl+X |
| **Mover** | Arrastar arquivo para pasta | Drag & drop |
| **Renomear** | Clicar direito > Renomear | F2 |
| **Deletar** | Clicar direito > Deletar ou Delete | Delete |
| **Restaurar** | Abrir Lixeira > Restaurar | — |
| **Buscar arquivo** | Usar busca no Explorador | Ctrl+F |

**Digitação e Atalhos Principais:**
- `Ctrl+S` → Salvar
- `Ctrl+Z` → Desfazer
- `Ctrl+Y` → Refazer
- `Ctrl+A` → Selecionar tudo
- `Alt+Tab` → Alternar entre janelas
- `Windows+E` → Abrir Explorador de Arquivos

---

### 4. Explorando o Explorador de Arquivos (20 min)

**Partes principais:**
- Painel esquerdo: Acesso rápido, Documentos, Downloads, etc.
- Painel central: Lista de arquivos/pastas
- Barra superior: Localização atual (caminho do arquivo)
- Botões de navegação: Voltar, Avançar, Para cima

**Dicas:**
- Copie o caminho de um arquivo para referência
- Use Visualização > Detalhes para ver tamanho e data
- Use Visualização > Miniaturas para ver imagens rapidamente

## Atividades Práticas

### Atividade 1: Organizar Pasta de Documentos (40 min)

Na sala de aula:
1. Criar pasta "Meus Documentos 2026"
2. Criar subpastas: Fotos, Vídeos, Trabalhos, Músicas
3. Baixar 2-3 imagens da internet
4. Mover imagens para pasta "Fotos"
5. Copiar um arquivo para "Trabalhos"
6. Renomear alguns arquivos

### Atividade 2: Jogos de Atalhos (20 min)

Competição:
- Qual aluno abre/salva arquivo mais rápido?
- Qual aluno usa mais atalhos corretos?
- Usar Ctrl+C, Ctrl+V, Ctrl+Z, Ctrl+A, etc.

### Atividade 3: Limpeza da Lixeira (20 min)

Prática de segurança:
- Deletar arquivos propositalmente
- Abrir Lixeira
- Observar que dados não foram perdidos
- Restaurar alguns
- Esvaziar Lixeira
