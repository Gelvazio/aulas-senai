## Conteúdo Programático

### 1. O que é Hardware? (30 min)

**Hardware = Partes Físicas (duro)**

São os componentes que você pode tocar, ver e pegar.

**Componentes Principais:**

| Componente | Função |
|---|---|
| **Processador (CPU)** | Cérebro do computador; realiza cálculos |
| **Memória RAM** | Memória temporária; guarda dados enquanto trabalha |
| **Disco Rígido (HDD/SSD)** | Armazena programas e arquivos permanentemente |
| **Placa-mãe** | Conecta todos os componentes |
| **Fonte de Alimentação** | Fornece energia |
| **Monitor** | Exibe imagens |
| **Teclado** | Entrada de dados |
| **Mouse** | Entrada de dados |
| **Impressora** | Saída de dados (impressão) |
| **Câmera** | Entrada de imagens |
| **Alto-falante** | Saída de áudio |

**Analogia:** Hardware é como o corpo humano — coração, pulmões, braços, pernas.

---

### 2. O que é Software? (30 min)

**Software = Programas/Aplicativos (mole)**

Conjunto de instruções que dizem ao hardware o que fazer. Não é físico — é digital.

**Tipos de Software:**

| Tipo | Exemplos |
|---|---|
| **Sistema Operacional** | Windows, macOS, Linux, Android, iOS |
| **Aplicativos** | Word, Excel, Photoshop, Google Chrome |
| **Jogos** | Fortnite, Minecraft, Roblox |
| **Apps de Celular** | WhatsApp, Instagram, TikTok |
| **Antivírus** | Windows Defender, Avast, Norton |
| **Navegador** | Chrome, Firefox, Safari, Edge |

**Analogia:** Software é como a mente/consciência — pensa, toma decisões, controla o corpo.

---

### 3. Hardware + Software = Computador Funcionando (20 min)

**Sem hardware:** Não há lugar para software rodar.  
**Sem software:** Hardware é inútil (não sabe o que fazer).

**Exemplo Prático — Reproduzir um Vídeo:**

1. **Hardware envolvido:**
   - Disco rígido (lê o arquivo do vídeo)
   - Processador (decodifica o vídeo)
   - Memória RAM (buffer temporário)
   - Placa de vídeo (renderiza imagens)
   - Monitor (mostra as imagens)
   - Alto-falante (toca o som)

2. **Software envolvido:**
   - Sistema Operacional (gerencia recursos)
   - Aplicativo (VLC, YouTube, etc.)
   - Driver de vídeo (instruções específicas para placa gráfica)
   - Driver de áudio (instruções para alto-falante)

---

### 4. Tipos de Sistemas Operacionais (20 min)

**O que é um SO?** Software principal que controla o hardware e permite executar outros programas.

| SO | Dispositivos | Características |
|---|---|---|
| **Windows** | PC, Notebook | Mais comum em trabalho/escritório |
| **macOS** | MacBook, iMac | Popular entre designers/criadores |
| **Linux** | Servidores, PCs | Grátis, código aberto, seguro |
| **ChromeOS** | Chromebooks | Leve, rápido, focado na nuvem |
| **Android** | Smartphones, Tablets | Mais usado no mundo |
| **iOS** | iPhone, iPad | Exclusivo Apple, seguro |

**Funções do SO:**
- Gerenciar hardware (CPU, memória, disco)
- Permitir instalação de programas
- Gerenciar arquivos e pastas
- Controlar períféricos (mouse, teclado, impressora)
- Fornecer interface amigável

## Estratégias de Ensino

1. **Demonstração prática:** Abrir um computador e mostrar componentes internos (ou vídeo)
2. **Apresentação visual** com imagens dos componentes
3. **Comparação lado a lado:** Hardware vs Software em tabela
4. **Atividade interativa:** Identificar SO do seu dispositivo

---

## Atividades Práticas

### Atividade 1: Dissecação de Computador (30 min)

**Opção A (com hardware real):** Se possível, desmontar um CPU antigo
- Apontar processador, memória, disco rígido, fonte
- Explicar função de cada componente

**Opção B (virtual):** Usar vídeo de desassembly no YouTube

### Atividade 2: Inventário de Hardware e Software (30 min)

Em duplas, usar um PC/notebook da sala:
1. Listar 10 componentes de hardware (mouse, teclado, monitor, etc.)
2. Listar 10 softwares instalados (Chrome, Word, Antivírus, etc.)
3. Descrever o SO instalado
4. Apresentar para turma (2 min)

### Atividade 3: Diagrama Hardware-Software (20 min)

Desenhar um diagrama mostrando:
- Central: CPU
- Setas saindo: RAM, Disco, Monitor, Teclado, Mouse
- Acima: Sistema Operacional como "controlador"
- Ao lado: Aplicativos (Word, Chrome, VLC, etc.)
