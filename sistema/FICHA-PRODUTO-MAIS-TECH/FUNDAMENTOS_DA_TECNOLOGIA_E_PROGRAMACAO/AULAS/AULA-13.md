## Conteúdo

### 1. O que é Programação? (15 min)

**Definição:** Escrever instruções em linguagem que computador entenda.

**Analogia:** Como dar ordem para robô fazer algo
- ❌ "Faça café" (muito vago)
- ✓ "Pegue xícara, coloque pó, adicione água quente, mexa" (específico)

**Por que programar?**
- Automatizar tarefas repetitivas
- Criar softwares e apps
- Resolver problemas complexos
- Carreira bem remunerada

### 3. Conceitos Básicos — Variáveis e Tipos de Dados (20 min)

**O que é uma Variável?**
- Caixinha que armazena valor
- Tem um nome identificador
- Pode guardar diferentes tipos de dados
- Valor pode ser alterado durante programa

**Exemplos de Variáveis:**
```
Nome = "João"
Idade = 14
Nota = 8.5
Aprovado = Verdadeiro
```

---

### 4. Tipos de Dados (15 min)

| Tipo | Exemplos | Uso |
|---|---|---|
| **Texto (String)** | "Rio do Sul", "João", "Olá mundo" | Nomes, mensagens |
| **Número Inteiro** | 10, 100, -5, 0 | Idades, pontuação, contador |
| **Número Decimal** | 3.14, 2.5, 9.99 | Notas, preços, medidas |
| **Booleano** | Verdadeiro, Falso | Decisões, ligado/desligado |
| **Lista** | [1, 2, 3], ["a", "b"] | Múltiplos valores |

**Analogia:** Tipo de dado é como o rótulo em uma caixa — diz o que você vai guardar lá dentro.

### 5. Operadores (15 min)

**Operadores Matemáticos:**
```
+  adição:      5 + 3 = 8
-  subtração:   5 - 3 = 2
*  multiplicação: 5 * 3 = 15
/  divisão:     15 / 3 = 5
%  resto:       10 % 3 = 1
```

**Operadores de Comparação:**
```
>   maior que:        5 > 3 = Verdadeiro
<   menor que:        5 < 3 = Falso
==  igual a:          5 == 5 = Verdadeiro
!=  diferente de:     5 != 3 = Verdadeiro
>=  maior ou igual:   5 >= 5 = Verdadeiro
<=  menor ou igual:   3 <= 5 = Verdadeiro
```

**Operadores Lógicos:**
```
E (AND):    Verdadeiro E Verdadeiro = Verdadeiro
            Verdadeiro E Falso = Falso
            
OU (OR):    Verdadeiro OU Falso = Verdadeiro
            Falso OU Falso = Falso
            
NÃO (NOT):  NÃO Verdadeiro = Falso
            NÃO Falso = Verdadeiro
```

**Exemplo Combinado:**
```
Idade = 14
Nota = 8.5

SE (Idade >= 13) E (Nota >= 7)
   IMPRIMIR "Aluno adolescente aprovado"
SENÃO
   IMPRIMIR "Não atende critérios"
```

### 7. Estrutura de Programa (10 min)

**Todo programa tem:**
1. **Entrada:** Receber dados do usuário
2. **Processamento:** Realizar cálculos/lógica com dados
3. **Saída:** Mostrar resultado

**Exemplo simples — Calcular Área:**
```
PROGRAMA: Calcular área de quadrado

1. Entrada: Receber lado do quadrado
2. Processamento: área = lado × lado
3. Saída: Mostrar resultado "Área = X"
```

**Outro Exemplo — Verificar Maioridade:**
```
PROGRAMA: Verificar se é maior de idade

1. Entrada: Receber idade da pessoa
2. Processamento: 
   SE idade >= 18
      resultado = "Maior"
   SENÃO
      resultado = "Menor"
3. Saída: Mostrar resultado
```
