# GOOGLE SHEETS vs MICROSOFT EXCEL

**Planilhas Eletrônicas • Análise de Dados ⭐**

---

## 1. Google Sheets - Visão Geral

**Plataforma:** Web-based + app desktop

**Custo:** Gratuito com Google Account

**Sync:** Google Drive (nuvem nativa)

**Ideal para:** Análise colaborativa leve, relatórios dinâmicos

☁️ Nuvem

🔄 Colaboração

⚠️ Limitado

## 2. Fórmulas e Funções (Sheets)

**Função QUERY:** Filtra e agrupa dados (SQL-like)

**FILTER:** Dinâmico, sem helper columns

**IMPORTRANGE:** Dados de outras planilhas

**Funções:** 400+ (suficiente, não completas)

**Macros:** Google Apps Script (JavaScript)

💡 Criativas

## 3. Colaboração em Tempo Real

✓ Múltiplos usuários simultaneamente

✓ Histórico de versões automático

✓ Comentários e sugestões integradas

✓ Permissões granulares instantâneas

✓ Share via link ou email

## 4. Análise de Dados (Sheets)

**Gráficos:** 15+ tipos, automáticos

**Tabelas dinâmicas:** Básicas

**Filtros:** Simples, sem macro

**Validação:** Dropdowns, listas

**Formato condicional:** Cores automáticas por condição

#### ✅ Vantagens Google Sheets

Colaboração real-time com múltiplos usuários

Acesso remoto perfeito, sem instalação

Histórico de versões infinito e automático

Integração com Google Forms e Data Studio

## 1. Microsoft Excel - Visão Geral

**Plataforma:** Desktop + Web + OneDrive

**Custo:** Microsoft 365 (assinatura)

**Sync:** OneDrive (opcional), offline-first

**Ideal para:** Análise complexa, modelagem, dados grandes

⚡ Poderoso

📊 Profissional

💰 Pago

## 2. Fórmulas Avançadas (Excel)

**500+ funções:** Completas e poderosas

**FILTER, SORT, UNIQUE:** Dinâmicas (365)

**XMatch, VLOOKUP avançado:** Busca robusta

**Solver:** Otimização não-linear

**VBA/Macros:** Automação profunda

🔧 Customizável

## 3. Desempenho em Grandes Dados

✓ 1.048.576 linhas × 16.384 colunas

✓ Manipula milhões de dados rápido

✓ Análise de sensibilidade integrada

✓ Cache e otimização automática

✓ Power Query para ETL

## 4. Análise e Visualização (Excel)

**Tabelas dinâmicas:** Avançadas, slicers

**Gráficos:** 20+ tipos, sparklines

**Análise rápida:** Recomendações automáticas

**3D Maps:** Visualização geográfica

**Power Pivot:** OLAP multiator

#### ✅ Vantagens Microsoft Excel

Análise de dados poderosa e profissional

Fórmulas avançadas e customização total

Desempenho em datasets gigantescos

Padrão corporativo para finanças e BI

| Recurso | Google Sheets | Microsoft Excel |
| --- | --- | --- |
