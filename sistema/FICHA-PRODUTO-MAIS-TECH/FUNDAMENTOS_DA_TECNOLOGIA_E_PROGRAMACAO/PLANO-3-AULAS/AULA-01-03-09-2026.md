## Conteúdo Programático

### 1. Introdução a Editores de Texto (15 min)

**O que é um editor de texto?** Software que permite criar, editar e formatar documentos com letras, números e símbolos.

**Diferenças entre editores:**

| Aspecto | Word (Microsoft) | Google Docs |
|---|---|---|
| **Acesso** | Instalado no PC | Na nuvem (internet) |
| **Custo** | Pago (Office 365) | Gratuito |
| **Salvamento** | Automático em pasta local | Automático na nuvem |
| **Colaboração** | Limitada (compartilhar arquivo) | Tempo real com vários usuários |
| **Offline** | Funciona sem internet | Precisa de conexão |
| **Compatibilidade** | .docx, .doc | Google Docs, pode exportar .docx |

---

### 2. Microsoft Word — Fundamentos (30 min)

**Interface Principal:**
- Fita de Opções (Home, Insert, Design, Layout, etc.)
- Área de Documento
- Painel de Navegação (esquerda)
- Status Bar (embaixo)

**Operações Básicas:**
- Criar novo documento (Ctrl+N)
- Abrir arquivo (Ctrl+O)
- Salvar (Ctrl+S)
- Salvar como (Ctrl+Shift+S)

**Formatação de Texto:**
- **Negrito** (Ctrl+B)
- *Itálico* (Ctrl+I)
- <u>Sublinhado</u> (Ctrl+U)
- Tamanho da fonte
- Cor do texto
- Destaque (fluorescente)

**Formatação de Parágrafo:**
- Alinhamento: Esquerda, Centro, Direita, Justificado
- Espaçamento entre linhas (simples, 1.5, duplo)
- Recuo de parágrafo (esquerda, direita, primeira linha)
- Espaçamento antes/depois do parágrafo

**Listas e Numeração:**
- Listas com bullets (•, ◦, ■)
- Listas numeradas (1., a., i.)
- Listas aninhadas (subníveis)

---

### 3. Word — Recursos Avançados (20 min)

**Inserir Elementos:**
- Imagens (Insert > Pictures)
- Tabelas (Insert > Table)
- Formas e caixas de texto
- Cabeçalhos e rodapés
- Números de página

**Estilos e Temas:**
- Aplicar estilos predefinidos (Heading 1, Heading 2, Normal)
- Criar estilos personalizados
- Mudar tema/cores do documento

**Verificação:**
- Correção ortográfica automática
- Verificador de gramática
- Revisor (Track Changes)

**Salvamento e Compartilhamento:**
- Salvar como PDF
- Salvar como .docx, .doc
- Enviar por email
- Compartilhar via OneDrive

---

### 4. Google Docs — Fundamentos (25 min)

**Acesso e Interface:**
- Acessar em: docs.google.com
- Login com conta Google
- Criar novo documento
- Interface simplificada (similar ao Word, mas na web)

**Operações Básicas em Google Docs:**
- Novo documento (Ctrl+N)
- Abrir arquivo (Ctrl+O)
- Salvar automático (nuvem)
- Renomear documento

**Formatação:**
- Mesmas opções de Word (negrito, itálico, sublinhado, cores)
- Estilos de parágrafo (Heading 1, Heading 2, Body text)
- Listas e numeração

**Colaboração em Tempo Real:**
- Compartilhar com outros usuários
- Definir permissões: Visualizar, Comentar, Editar
- Ver alterações de outros em tempo real
- Histórico de versões (File > Version history)
- Comentários e sugestões

**Diferenças Google Docs vs. Word:**
- ✓ Múltiplos usuários editando simultaneamente
- ✓ Histórico automático de versões
- ✓ Acessível de qualquer dispositivo
- ✓ Não precisa instalar software
- ✗ Alguns recursos avançados do Word não existem
- ✗ Depende de conexão à internet

---

### 5. Exportação e Compartilhamento (10 min)

**Google Docs → Outros Formatos:**
- Download como .docx (Word)
- Download como PDF
- Download como .odt (OpenDocument)
- Publicar como página web

**Word → Nuvem:**
- Salvar em OneDrive
- Compartilhar link
- Coautoria (máximo 10 usuários simultâneos)

## Atividades Práticas

### Atividade 1: Criar Documento Profissional no Word (35 min)

**Tarefa:** Escrever um "Currículo Escolar" com formatação profissional

**Estrutura:**
- Título: "CURRÍCULO ESCOLAR" (Heading 1, Negrito, Centro)
- Nome completo (fonte 14pt)
- Dados pessoais: Data de nascimento, Telefone, Email (tabela com 2 colunas)
- Seções:
  - Objetivo (1 parágrafo)
  - Experiência Escolar (lista)
  - Habilidades (lista com bullets)
  - Idiomas (tabela)

**Requisitos:**
- ✓ Mínimo 1 imagem (foto)
- ✓ Usar mínimo 3 estilos diferentes (Heading, Normal, List)
- ✓ Espaçamento adequado
- ✓ Cores coordenadas

**Entrega:** Salvar como PDF + .docx

### Atividade 2: Colaboração no Google Docs (30 min)

**Tarefa:** Criar documento colaborativo — "Plano de Projeto de Classe"

**Procedimento:**
1. Professor cria documento vazio no Google Docs
2. Compartilha link com permissão "Editar"
3. Divide turma em 4 grupos:
   - Grupo 1: Escrever objetivo
   - Grupo 2: Escrever cronograma (tabela)
   - Grupo 3: Listar recursos necessários
   - Grupo 4: Listar responsáveis (nomes)
4. Todos editam simultaneamente (15 min)
5. Revisar documento completo (5 min)
6. Ver histórico de versões (5 min)

**Aprendizado:** Colaboração em tempo real, evitar conflitos de edição

### Atividade 3: Conversão de Formatos (20 min)

**Prática:**
1. Abrir documento Word já pronto
2. Exportar como PDF (Word)
3. Abrir mesmo documento no Google Docs
4. Exportar como .docx (Google Docs)
5. Verificar diferenças de formatação

**Discussão:** Qual formato preserva melhor a formatação?
