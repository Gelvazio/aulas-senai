## CONTEÚDO PROGRAMÁTICO
## 1. CONCEITOS FUNDAMENTAIS

### 1.1 Definições Básicas
- **Dados:** Informações brutas coletadas
- **Amostra:** Subconjunto de dados da população
- **Variável:** Características que podem variar (ex: salário, idade, vendas)
- **Frequência:** Número de vezes que um valor aparece

### 1.2 Tipos de Dados
- **Quantitativos:** Números (idade, salário, quantidade)
- **Qualitativos:** Categorias (sexo, departamento, produto)

## 2. MEDIDAS DE TENDÊNCIA CENTRAL

### 2.1 Média Aritmética
- **Fórmula:** Soma de todos valores / Quantidade de valores
- **Exemplo:** Vendas diárias: 100, 120, 150, 130 → Média = 400/4 = 100
- **Uso:** Análise geral de desempenho
- **Em Excel:** =MÉDIA(intervalo)

### 2.2 Mediana
- **Definição:** Valor que divide o conjunto ao meio
- **Cálculo:** Ordenar dados e pegar o valor do meio
- **Exemplo:** 100, 120, 130, 150, 200 → Mediana = 130
- **Uso:** Evita distorção de dados extremos
- **Em Excel:** =MED(intervalo)

### 2.3 Moda
- **Definição:** Valor que mais frequentemente aparece
- **Exemplo:** 100, 100, 120, 150, 200 → Moda = 100
- **Uso:** Identificar padrões de consumo
- **Em Excel:** =MODO(intervalo)

## 3. MEDIDAS DE DISPERSÃO

### 3.1 Amplitude
- **Fórmula:** Valor Máximo - Valor Mínimo
- **Exemplo:** 200 - 100 = 100
- **Uso:** Verificar variação geral

### 3.2 Variância
- **Definição:** Média dos quadrados das diferenças em relação à média
- **Uso:** Medir variabilidade dos dados
- **Em Excel:** =VAR(intervalo)

### 3.3 Desvio Padrão
- **Definição:** Raiz quadrada da variância
- **Interpretação:** Quanto os dados se desviam da média
- **Uso:** Analisar consistência de processos
- **Em Excel:** =DESVPAD(intervalo)

## 4. TABELAS DE FREQUÊNCIA

### 4.1 Construção
- Listar valores únicos
- Contar quantas vezes cada valor aparece
- Calcular frequência relativa (frequência / total)
- Calcular frequência acumulada

### 4.2 Exemplo Prático
- Dados de vendas por categoria
- Criar tabela com contagem de transações
- Analisar qual categoria tem maior frequência
