## CONTEÚDO PROGRAMÁTICO
## 1. INTERFACE DO EXCEL

### 1.1 Componentes Principais
- **Barra de Fórmulas:** Visualiza e edita conteúdo da célula selecionada
- **Linha de Nome:** Mostra endereço da célula ativa (ex: A1, B5)
- **Planilhas:** Abas na base do documento
- **Barra de Ferramentas:** Acesso rápido a funções
- **Menu Arquivo:** Salvar, abrir, imprimir documentos

### 1.2 Estrutura de Células
- **Linha:** Horizontal (numeradas 1, 2, 3...)
- **Coluna:** Vertical (nomeadas A, B, C...)
- **Célula:** Intersecção linha × coluna (ex: A1, B3)
- **Intervalo:** Conjunto de células (ex: A1:A10, B1:D5)

## 2. NAVEGAÇÃO BÁSICA

### 2.1 Movimentação
- **Setas:** Move uma célula por vez
- **Ctrl + Setas:** Move para fim de dados contínuos
- **Ctrl + Home:** Vai para célula A1
- **Ctrl + End:** Vai para última célula com dados
- **Ctrl + Page Down/Up:** Navega entre planilhas

### 2.2 Seleção
- **Clicar:** Seleciona uma célula
- **Arrasta:** Seleciona intervalo
- **Ctrl + Click:** Seleciona múltiplas células não contíguas
- **Shift + Click:** Seleciona até célula clicada

## 3. INSERÇÃO E FORMATAÇÃO DE DADOS

### 3.1 Entrada de Dados
- **Texto:** Digite e pressione Enter
- **Número:** Digite número sem espaços
- **Data:** Formato DD/MM/AAAA
- **Moeda:** Digite número, formato depois

### 3.2 Formatação Básica
- **Negrito:** Ctrl + B ou botão da barra
- **Itálico:** Ctrl + I
- **Sublinhado:** Ctrl + U
- **Cor de Fonte:** Menu Formato > Células
- **Cor de Fundo:** Menu Formato > Cor de Preenchimento

## 4. FÓRMULAS BÁSICAS

### 4.1 Construção
- Começar com sinal de =
- Usar referências de células (A1, B5, etc)
- Usar operadores: +, -, ×, ÷

### 4.2 Exemplos
- =A1+A2 (soma de duas células)
- =B5*0,1 (cálculo de 10% de B5)
- =(A1+A2)/2 (média de duas células)

## 5. GERENCIAMENTO DE PLANILHAS

### 5.1 Operações
- **Inserir planilha:** Botão direito na aba > Inserir
- **Renomear:** Botão direito na aba > Renomear
- **Mover:** Arrastar aba para nova posição
- **Deletar:** Botão direito > Deletar
