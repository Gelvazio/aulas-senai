## CONTEÚDO PROGRAMÁTICO
## 1. PREPARAÇÃO DE DADOS

### 1.1 Estrutura
- Tabela principal (fonte de dados)
- Não usar em dashboard diretamente
- Criar tabelas auxiliares para cálculos
- Referenciar com fórmulas

### 1.2 Cálculos Necessários
- Totalizações (SUM, AVERAGE)
- Comparações vs Meta
- Percentuais
- Variações (mês anterior, ano anterior)

### 1.3 Exemplo: Dados de Vendas
```
Tabela Original:
| Data | Vendedor | Produto | Valor |
|------|----------|---------|-------|

Tabela Auxiliar (Dashboard):
| Métrica | Valor | Meta | % |
|---------|-------|------|---|
| Vendas Total | 87.500 | 100.000 | 87% |
| Número Pedidos | 145 | 160 | 91% |
| Ticket Médio | 603 | 625 | 96% |
```

## 2. INTEGRAÇÃO DE ELEMENTOS

### 2.1 Células com KPIs
- Células grandes com fonte grande
- Fundo colorido (verde se OK, vermelho se não)
- Referências a células com cálculos
- Atualizam automaticamente

### 2.2 Gráficos Interligados
- Gráficos apontam para tabelas auxiliares
- Alterar dados → gráficos mudam
- Usar fórmulas para criar dados dinâmicos

### 2.3 Tabelas Dinâmicas
- Incorporar no dashboard
- Menos espaço que gráficos
- Mostrar top/bottom performers

## 3. INTERATIVIDADE

### 3.1 Filtros com Segmentador
- Inserir Slicer para tabela dinâmica
- Clicar em botão para filtrar
- Gráficos atualizamos automaticamente

### 3.2 Seletor de Período
- Lista suspensa com períodos
- Fórmulas ajustam dados conforme seleção
- Exemplo: Janeiro, Fevereiro, Acumulado

### 3.3 Validação de Dados
- Criar dropdown para escolha (Região, Categoria)
- Segmentadores de Excel
- Botões de opção para filtros

## 4. FORMATAÇÃO FINAL

### 4.1 Design Visual
- Paleta de cores consistente
- Usar branco generosamente (não poluído)
- Fontes legíveis (Arial, Calibri)
- Tamanho adequado para exibição em tela

### 4.2 Organização
- KPIs no topo (eye-catching)
- Gráficos abaixo para contexto
- Detalhes em abas secundárias se necessário
- Congelamento de painéis para fácil navegação

### 4.3 Exemplo: Divisão de Tela
```
┌────────────────────────────────────────┐
│ DASHBOARD DE VENDAS - OUTUBRO 2026     │
├────────────────────────────────────────┤
│ [KPI1]        [KPI2]        [KPI3]     │
│ META 100K     PEDIDOS 160   TICKET 625 │
│ REAL 87.5K    REAL 145      REAL 603   │
│ 87% ●         91% ●         96% ●      │
├────────────────────────────────────────┤
│ Tendência (6m)      │ Top 5 Vendedores │
│ [GRÁFICO LINHAS]    │ [TABELA]         │
├────────────────────────────────────────┤
│ Vendas por Região   │ Vendas por Produto
│ [GRÁFICO COLUNAS]   │ [GRÁFICO PIZZA]  │
└────────────────────────────────────────┘
```

## 5. APRESENTAÇÃO

### 5.1 Preparação
- Testar todos os filtros
- Verificar atualização de dados
- Confirmar cores e fontes
- Preparar narrativa/explicação

### 5.2 Durante Apresentação
- Mostrar KPIs principais primeiro
- Explicar cada métrica e meta
- Investigar anomalias visíveis
- Propor ações baseado em insights

### 5.3 Feedback
- Coletar sugestões dos usuários
- Ajustar métricas conforme necessário
- Adicionar novos KPIs
- Refinar design iterativamente
