## CONTEÚDO PROGRAMÁTICO
## 1. PROGRESSÕES ARITMÉTICAS (PA)

### 1.1 Conceito
- **Definição:** Sequência onde cada termo é igual ao anterior + uma constante (razão r)
- **Exemplo:** 2, 5, 8, 11, 14... (razão = 3)
- **Fórmula:** An = A1 + (n-1) × r

### 1.2 Aplicação
- Crescimento linear de vendas
- Aumento constante de preços
- Progressão de custos fixos

### 1.3 Exemplo Prático
- Se vendas começam em R$ 1.000 e crescem R$ 200/mês
- Mês 1: 1.000 | Mês 2: 1.200 | Mês 3: 1.400 | Mês 4: 1.600

## 2. PROGRESSÕES GEOMÉTRICAS (PG)

### 2.1 Conceito
- **Definição:** Sequência onde cada termo é o anterior × uma constante (razão q)
- **Exemplo:** 2, 6, 18, 54... (razão = 3)
- **Fórmula:** An = A1 × q^(n-1)

### 2.2 Aplicação
- Crescimento exponencial de dados
- Capitalização de investimentos
- Disseminação de informações em rede

### 2.3 Exemplo Prático
- Se um produto começa com 100 unidades e duplica a cada mês
- Mês 1: 100 | Mês 2: 200 | Mês 3: 400 | Mês 4: 800

## 3. IDENTIFICAÇÃO DE PADRÕES

### 3.1 Técnicas
1. Verificar diferença entre termos consecutivos (PA)
2. Verificar razão entre termos consecutivos (PG)
3. Observar mudanças de padrão
4. Extrair a regra matemática

### 3.2 Exemplo Análise
- Sequência: 3, 6, 12, 24, 48
- Razão: 6÷3=2, 12÷6=2, 24÷12=2
- Padrão: PG com razão 2
- Próximo: 48×2 = 96

## 4. PREVISÕES E TENDÊNCIAS

### 4.1 Aplicação em Gestão
- Prever crescimento de vendas
- Estimar demanda futura
- Planejar orçamento anual

### 4.2 Exemplo Prático
- Dados históricos: 100, 120, 140, 160 (PA com razão 20)
- Previsão para próx: 180, 200, 220
- Base para planejamento de compras e produção
