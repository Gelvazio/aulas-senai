## CONTEÚDO PROGRAMÁTICO
## 1. CONCEITO DE DASHBOARD

### 1.1 Definição
- Painel visual de informações gerenciais
- Resumo de métricas críticas
- Permite decisões rápidas baseadas em dados

### 1.2 Tipos de Dashboards
- **Operacional:** Monitoramento diário (estoque, vendas)
- **Gerencial:** Análise semanal/mensal (desempenho)
- **Estratégico:** Análise trimestral/anual (metas, crescimento)
- **Pessoal:** KPIs do vendedor, gerente, etc

### 1.3 Benefícios
- Visualizar informação complexa rapidamente
- Identificar problemas antes de ser crítico
- Facilitar tomada de decisão
- Comunicar desempenho para stakeholders

## 2. ELEMENTOS DE DASHBOARD

### 2.1 KPI (Indicador-Chave de Desempenho)
- **Métrica:** Vendas do mês
- **Meta:** R$ 100.000
- **Actual:** R$ 87.500
- **Status:** 87.5% (indicador visual: amarelo)

### 2.2 Gráficos
- Tendências (linhas)
- Comparações (colunas)
- Composição (pizza)
- Correlações (dispersão)

### 2.3 Indicadores Visuais
- Semáforo (vermelho/amarelo/verde)
- Seta (para cima/para baixo)
- Número grande destacado
- Medidor/gauge

### 2.4 Tabelas
- Resumo de top 10 produtos
- Ranking de vendedores
- Detalhes de exceções

## 3. DESIGN E LAYOUT

### 3.1 Boas Práticas
- **Simplicidade:** Apenas informações essenciais
- **Destaque:** Métricas críticas em lugar visível
- **Cores:** Limitar a 3-4 cores (+ branco)
- **Espaço:** Evitar poluição visual

### 3.2 Organização
- Agrupar por tema (Vendas, Estoque, RH)
- KPIs no topo (resumo executivo)
- Gráficos em ordem de importância
- Detalhe embaixo ou em aba secundária

### 3.3 Exemplo Layout
```
┌─────────────────────────────────────┐
│ VENDAS DO MÊS                       │
│ ┌──────┐ ┌──────┐ ┌──────┐         │
│ │ Meta │ │Real  │ │ %    │         │
│ │100K  │ │87.5K │ │ 87%  │         │
│ └──────┘ └──────┘ └──────┘         │
├─────────────────────────────────────┤
│ Tendência (6 meses) │ Top 5 Produtos│
│ [GRÁFICO LINHA]     │ [TABELA]      │
└─────────────────────────────────────┘
```

## 4. PLANEJAMENTO DE DASHBOARD

### 4.1 Etapas
1. **Objetivo:** O que decisor precisa saber?
2. **Públalvo:** Gerente, CEO, operação?
3. **Frequência:** Real-time, diário, semanal?
4. **Dados:** Qual fonte? Qual atualização?

### 4.2 Exemplo: Dashboard Gerente Vendas
- **Objetivo:** Monitorar desempenho de vendas
- **Público:** Gerente regional
- **Frequência:** Atualiza diariamente
- **KPIs:**
  - Total de vendas vs meta
  - Número de pedidos
  - Ticket médio
  - Top 5 clientes
  - Ranking de vendedores

### 4.3 Questões a Responder
1. Qual é o desempenho atual?
2. Como está comparado à meta?
3. Qual é a tendência?
4. Quem/o quê está causando?
5. Qual ação tomar?
