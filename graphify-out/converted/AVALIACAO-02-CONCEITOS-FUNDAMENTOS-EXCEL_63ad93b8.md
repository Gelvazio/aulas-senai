ITEM 1
CAPACIDADE: Estruturar planilha Excel com cabeçalhos

Contexto: Dados: Notebook, Mouse, Teclado, Monitor, Webcam com quantidades e preços. Colunas necessárias: Produto, Quantidade, Preço Unitário, Total, %.

Comando: Crie cabeçalhos em A1:E1, formate com letras MAIÚSCULAS, fundo cinza, texto branco. Qual é o endereço correto?

Alternativas:
a) A1:E1 com formatação especificada (maiúscula, cinza, branco, borda preta)
b) A1:E1 em texto simples sem formatação
c) A2:E2 com dados já preenchidos
d) F1:J1 deslocado para direita
e) A1:A5 apenas coluna A

ITEM 2
CAPACIDADE: Inserir dados de 5 produtos

Contexto: 5 produtos: Notebook (5, 3500), Mouse (20, 85), Teclado (15, 150), Monitor (8, 800), Webcam (12, 250). Identificar tipos de dados.

Comando: Insira dados em A2:C6. Qual é o tipo de cada coluna? (Texto/Número/Fórmula)

Alternativas:
a) Coluna A: Texto. Coluna B: Número. Coluna C: Número.
b) Todas as colunas são Texto.
c) Todas são Número.
d) Coluna A: Número. B e C: Texto.
e) Coluna A: Fórmula. B: Texto. C: Número.

ITEM 3
CAPACIDADE: Construir fórmula de multiplicação

Contexto: D2 deve conter Qtd × Preço (B2 × C2). Copiar para D3:D6.

Comando: Qual é a fórmula correta e o resultado esperado para Notebook?

Alternativas:
a) =B2*C2 → 5 × 3500 = 17.500
b) =B2+C2 → 5 + 3500 = 3.505
c) =B2/C2 → 5 ÷ 3500 = 0,0014
d) =C2^B2 → 3500^5 (muito grande)
e) =B2 C2 (sem operador, erro)

ITEM 4
CAPACIDADE: Calcular soma com função SOMA

Contexto: D7 deve somar todos os totais D2:D6 (17.500 + 1.700 + 2.250 + 6.400 + 3.000).

Comando: Qual fórmula e resultado correto?

Alternativas:
a) =SOMA(D2:D6) → 30.850
b) =SUM(D2:D6) → 30.850 (sintaxe inglesa)
c) =D2+D3+D4+D5+D6 → 30.850 (manual, funciona)
d) =TOTAL(D2:D6) → erro (função não existe)
e) =MÉDIA(D2:D6) → 6.170 (média, não soma)

ITEM 5
CAPACIDADE: Criar fórmula de porcentagem com referência absoluta

Contexto: E2 calcula % do produto sobre total (D2 ÷ D7 × 100). Usar $ para travar D7.

Comando: Qual fórmula garante que ao copiar para E3:E6, D7 não mude?

Alternativas:
a) =D2/*100 ($ trava linha e coluna D7)
b) =D2/D7*100 (sem $, D7 muda para D8, D9, ...)
c) =/*100 (trava D2, problema)
d) =D2/D*100 (trava só linha, não é o ideal)
e) =D2%7*100 (sintaxe errada)

ITEM 6
CAPACIDADE: Aplicar funções de agregação

Contexto: Coluna D com valores: 17500, 1700, 2250, 6400, 3000. Criar linha com SOMA, MÁXIMO, MÍNIMO, MÉDIA.

Comando: Qual é o resultado CORRETO de cada função?

Alternativas:
a) SOMA=30850, MÁX=17500, MÍN=1700, MÉD=6170
b) SOMA=30000, MÁX=15000, MÍN=500, MÉD=5000
c) SOMA=30850, MÁX=30850, MÍN=1000, MÉD=10000
d) Impossível sem tabelas dinâmicas
e) SOMA=25000, MÁX=10000, MÍN=1000, MÉD=5000

ITEM 7
CAPACIDADE: Formatar células como moeda

Contexto: Colunas C e D (Preço Unitário e Total) devem mostrar valores com R$ e 2 casas decimais.

Comando: Qual é a formatação correta e resultado para 17.500?

Alternativas:
a) Formato Moeda, símbolo R$, 2 decimais → R$ 17.500,00
b) Formato Número, símbolo $ → \$ 17.500
c) Formato Contábil → (17.500)
d) Formato Percentual → 1.750.000%
e) Sem formatação → 17500

ITEM 8
CAPACIDADE: Aplicar formatação de porcentagem

Contexto: Coluna E (% do Total) com valores: 56,72%, 5,50%, 7,29%, 20,74%, 9,72%.

Comando: Qual formato a aplicar para mostrar corretamente e fórmula para Notebook?

Alternativas:
a) Formato Porcentagem, 2 decimais. Fórmula: =D2/*100
b) Formato Número 2 decimais. Fórmula: =D2/D7
c) Formato Texto com símbolo % manual
d) Sem formatação especial, deixar como está
e) Formato Científico: 5,67E+01
