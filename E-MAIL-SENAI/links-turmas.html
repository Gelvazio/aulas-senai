Como usar
  1. Clique em Projetar na turma e mostre o QR Code no telão.
  2. Os alunos apontam a câmera do celular e preenchem nome e e-mail.
  3. Os cadastros aparecem no dashboard com origem AUTOCADASTRO.
  4. Terminada a aula, clique em Desativar para fechar o link.

Quem abre o link só consegue gravar o próprio e-mail — nunca ler os dados dos colegas. Isso é garantido pelo banco, não pela tela.
